# Клубы (цикл 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Клуб фитнес-зала: заявка → модерация админом приложения → поиск и вступление → рейтинг по XP и лента событий участников, управление клубом его админом. Под флагом `clubs`.

**Architecture:** Новый модуль `lib/club/*` по образцу гильдии: чистые правила (`rules.ts`, `feed.ts`) с unit-тестами, SQL-запросы (`queries.ts`), server actions (`actions.ts`, `admin-actions.ts`). Рейтинг — та же сумма `XpEvent`, что у лиги, и `rankLeague`. Лента — свой узкий SQL (без упражнений, объёма, 👊) + чистая `toClubEvents`. Страницы — `app/(app)/clubs/**` и `app/(app)/admin/clubs`.

**Tech Stack:** Next.js 16 (App Router, server actions), Prisma 7 + PostgreSQL, Zod, shadcn/ui (Base UI), Vitest, Playwright, `uqr` (QR в SVG).

**Spec:** `docs/superpowers/specs/2026-10-12-clubs-design.md`

## Global Constraints

- Ветка: фича `feat/clubs` от `release/2026-11-assistant`, по готовности — `--no-ff` в релизную, ветка удаляется.
- Флаг `clubs` в `FLAGS`, `expires: "2027-03-31"`. Без флага у смотрящего: нет пунктов меню, `/clubs/**` — `notFound()`, действия — `{ ok: false, error: "Клубы пока недоступны" }`. `/admin/clubs` и действия модерации — без флага, только `requireAdmin`.
- Лимиты: название 3–60, город 2–40, адрес 5–120, контакт 5–120, причина отказа 5–200; `CLUB_ADMIN_MAX = 5`, `CLUB_PENDING_MAX = 3`; поиск до 30, подсказки городов до 8, похожие до 5, рейтинг топ-50 (не участнику — топ-3 недели).
- Один клуб на человека (`ClubMember.userId` — ключ); вступление требует ник; исключение = `ClubBan`.
- Контакт зала (`Club.contact`) не уходит в браузер никому, кроме `/admin/clubs`.
- В ленту клуба не попадают: название тренировки, упражнения, объём, длительность, id тренировки, 👊, тренировки до `joinedAt`, авторы с `shareActivity = false`. `hideWeights` — `value: null` у весовых рекордов (`ONE_RM`, `MAX_WEIGHT`).
- Тексты: «Админ клуба ограничил вступление», «Можно управлять не больше чем 5 клубами», «Не больше 3 заявок на проверке», «Клуб скрыт модератором», «Возможно, ваш зал уже есть», согласие: «Участники клуба увидят твой ник, уровень, опыт и достижения. Тренировки — нет.»
- Цвета — только семантические токены; ссылка-кнопка — `<Link className={buttonVariants()}>`; в e2e переключатели — по роли `switch`.
- После добавления `uqr`: `docker run --rm -v "$PWD:/app" -w /app node:24 npm install --package-lock-only --ignore-scripts`.

## Review Focus

- Клуб скрыли/отклонили между открытием экрана вступления и нажатием — `joinClubAction` отказывает (проверка статуса внутри транзакции под `FOR UPDATE`). Тест — Task 6.
- Поиск со спецсимволами `%`, `_`, `\` — ищутся буквально, не как шаблон `ILIKE`. Тест — Task 1 (`likePattern`) и Task 5 (e2e «100%»).

- Передача клуба себе, не участнику или человеку с 5 клубами; исключение самого админа клуба — понятный отказ. Тест — Task 1 (`transferBlock`, `kickBlock`).
- Два модератора одновременно решают одну заявку — одно решение, одно уведомление (условный `updateMany` по `status: PENDING`, уведомление только при `count === 1`). Тест — Task 4 (повторное решение уже решённой → «Заявка уже рассмотрена»).
