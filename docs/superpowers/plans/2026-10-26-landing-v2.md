# Лендинг v2 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Переписать `/` в ветке `exp/landing-v2`: 11 секций, живые макеты телефона, бенто-инфографика, современный вид, обе темы.

**Architecture:** Серверная страница `app/(marketing)/page.tsx` собирает данные (как сейчас) и рендерит секции из `components/marketing/v2/`. Макеты экранов — серверные компоненты на токенах; анимации — клиентские острова на существующих `Reveal`/`CountUp` (Motion) и одном новом хуке видимости.

**Tech Stack:** Next.js 16, Tailwind (токены `app/globals.css`), Motion + NumberFlow (уже есть), lucide-react, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-26-landing-v2-design.md`

## Global Constraints

- Ветка `exp/landing-v2`, никуда не вливается, не пушится без просьбы.
- Новые зависимости — нет. Цвета — только семантические токены (`primary`, `xp`, `streak`, `chart-*`, `muted`, `card`…), обе темы.
- Бесконечных анимаций нет; всё при прокрутке и один раз; `prefers-reduced-motion` — финальное состояние (`MotionProvider` уже даёт `reducedMotion="user"`).
- Тексты — только правда; нет выдуманных отзывов/чисел; совместная тренировка не упоминается; «11 групп мышц».
- Флаги — как сейчас: клубы `isEnabled("clubs", null)`, Android `native_app`, Telegram `telegramEnabled()`, «Найти тренера» — `showCatalogOnLanding(catalogCount())`.
- Без изменений: `metadata`, `structured` JSON-LD (`WebSite`, `SoftwareApplication`, `FAQPage`), редирект/«Открыть кабинет» для вошедших, `Faq`/`faqFor`.
- Якоря: `#how`, `#features`, `#game`, `#guilds`, `#clubs`, `#coaches`, `#compare`, `#android`, `#pricing`, `#faq`.
- Ссылка-кнопка — `<Link className={buttonVariants()}>`.
- Тексты, на которые опираются тесты (точно):
  - h1: «Дневник тренировок, который не даст бросить» (градиент на «не даст бросить»);
  - строка доверия: «Бесплатно · без рекламы · сайт» + «, Android» (при `native_app`) + «, Telegram» (при Telegram);
  - секции (h2 = имя region): «Три шага до нового уровня», «Всё для прогресса», «Игра, которая держит», «Вместе веселее», «Ведите клиентов там, где им интересно тренироваться», «Чем Hero Fit лучше блокнота», «Где тренироваться с Hero Fit», «Сейчас всё бесплатно», «Частые вопросы», финал «Первый уровень — уже после первой тренировки»;
  - вкладки «Вместе веселее»: «Друзья и лига», «Гильдии и рейды», «Клубы залов»; в «Гильдии и рейды» — ссылка «Собрать гильдию» → `/register`;
  - тренерам: 4 пункта списка, ссылки «Стать тренером — бесплатно» → `/register?coach=1`, «Найти тренера» → `/trainers` (по условию);
  - платформы: Android-карточка — region «Приложение для Android» со ссылками «Скачать APK» и «Как подключить уведомления»; Telegram — ссылка «Открыть в Telegram».

## Review Focus

1. Ширина 360 px: ни одна секция (телефон, бенто, таблица сравнения, вкладки) не даёт горизонтальной прокрутки — проверка `scrollWidth <= innerWidth` в e2e Task 6.
2. Светлая тема: свечения и градиенты не превращают текст в нечитаемый — скриншоты обеих тем в Task 6, смотрю глазами.
3. «Уменьшить движение»: полоса XP и цифры сразу в финале, таймер не тикает — e2e с `reducedMotion: "reduce"` (по умолчанию в конфиге) видит финальные значения.
4. Флаги выключены (клубы, Android, Telegram): вкладка и карточки исчезают без пустых дыр в сетке — e2e Task 6 (`landing-android.spec` уже проверяет выключенный Android).
5. Клавиатура: вкладки «Вместе веселее» переключаются стрелками/Tab (Base UI `Tabs`), фокус виден — e2e Task 4.

**Files:**
- Create: `components/marketing/v2/phone-frame.tsx`, `components/marketing/v2/section.tsx`, `components/marketing/v2/screens/dashboard-screen.tsx`, `.../workout-screen.tsx`, `.../boss-screen.tsx`, `.../clients-screen.tsx`, `components/marketing/v2/use-in-view-once.ts`

**Interfaces:**
- Produces:
  - `PhoneFrame({ children, tilt?: "left" | "right" | "none", className?, label: string })` — `role="img"` + `aria-label={label}` (макет — иллюстрация), рамка `rounded-[2.5rem]`, «чёлка», цветная тень `shadow-[0_30px_80px_-20px_color-mix(in_oklch,var(--primary)_45%,transparent)]`, `tilt` — `lg:[transform:perspective(1200px)_rotateY(±8deg)]`; ширина 260–300 px.
  - `Section({ id?, eyebrow, title, lead?, children, className? })` — `<section aria-labelledby>` + бейдж-капсула + h2 `font-display` + лид.
  - `GradientText({ children })` — `bg-gradient-to-r from-primary to-xp bg-clip-text text-transparent`.
  - Экраны (клиентские, анимации при первом показе через `useInViewOnce(ref)`): `DashboardScreen` (уровень 12, XP-бар 0 → 68 %, серия «6 недель 🔥», карточка «Начать тренировку»), `WorkoutScreen` (упражнение «Присед», 3 подхода, третий отмечается; таймер отдыха 1:30 → тикает, пока виден), `BossScreen` (босс недели, полоса HP 100 → 35 %, урон «−1 240»), `ClientsScreen` (5 клиентов, у двух сигналы «7 дней без тренировок», «новый рекорд»).
  - `useInViewOnce(ref): boolean` — `IntersectionObserver`, true один раз.
