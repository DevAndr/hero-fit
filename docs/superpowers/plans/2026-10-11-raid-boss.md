# Рейд-босс гильдии Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Общий босс недели у гильдии: тренировки участников бьют его вместе с личным боссом, победа даёт сундук всем бившим, MVP — бонус.

**Architecture:** Чистые правила — `lib/raid/rules.ts`; рейд (`RaidWeek`) создаётся лениво, вклад каждой тренировки пишется строкой `RaidHit` в транзакции `finishWorkout` (под `SELECT … FOR UPDATE` строки рейда), победа создаёт `RaidReward`. UI — блок на `/guild`, полоса в `GuildCard` и в сводке; напоминание в четверг — шаг `runNotificationTick`.

**Tech Stack:** Next.js 16, Prisma 7 (Postgres), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-11-raid-boss-design.md`

## Global Constraints

- HP: доля участника — среднее урона по неделям с уроном среди 4 прошлых (в его поясе), без таких недель — 1000; сумма × 1,2, до сотни, минимум 1500.
- Урон — `workoutDamage` из `lib/boss/damage.ts` (без своих формул).
- Засчитывается тренировка с `finishedAt ∈ [startsAt, endsAt)` и `finishedAt ≥ joinedAt`.
- Рейд-босс — `BOSSES` со сдвигом ротации на 6 недель; имя «Древний <имя>».
- Награда: `min(400, round(hp / hitters / 20))`, MVP × 1,5 (округление); только бившим до победы и состоящим в гильдии в момент победы; открыть — 4 недели после победы, только будучи в этой гильдии.
- Напоминание: с чт 12:00 в поясе главы, не повержен, один раз на рейд; текст «Гильдии не хватает N урона — до конца рейда 4 дня».
- Уведомления `NotificationType.RAID`, push — по `notifyAchievements` (как `BOSS`); XP — `XpReason.RAID_REWARD` (не в лиге и не в ленте).
- Тексты интерфейса — русские, как в спеке; цвета — только семантические токены.
- Миграции — `npx prisma migrate dev --name guild_raids` (частичные индексы прежних миграций не трогать).

## Review Focus

- Два участника завершают тренировки одновременно на пороге HP → ровно одна победа, обе строки урона записаны (блокировка строки рейда).
- Повторный вызов `finishWorkout` той же тренировки (офлайн-очередь) → второй `RaidHit` не создаётся (`workoutId @unique`, пропуск при наличии).
- Глава сменил пояс посреди недели → рейд недели остаётся тем же (поиск по окну `startsAt ≤ now < endsAt`, а не по пересчитанному ключу).
- Игрок без гильдии завершает тренировку → `FinishMeta.raid` нет, ошибок нет.
- Участник открывает сундук вне окна 4 недель или после выхода → «Сундук недоступен», XP не начислен.
