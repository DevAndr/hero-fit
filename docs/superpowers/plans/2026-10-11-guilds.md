# Гильдии (рейды, цикл 1) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** игроки создают гильдию до 10 человек, зовут ссылкой, видят состав с недельными цифрами и ленту гильдии.

**Architecture:** `Guild` + `GuildMember` (userId — ключ); чистые правила `lib/guild/rules.ts`; actions с блокировкой строки гильдии при вступлении; лента — общий `feedPage` по списку авторов.

**Tech Stack:** Next.js 16, Prisma 7 (pg adapter), Zod, Base UI, lucide, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-11-guilds-design.md`

## Global Constraints

- Ветка `feat/guilds` от `release/2026-10-raids`; по готовности — вливается в релизную ветку (`--no-ff`), без PR.
- Одна гильдия на игрока, ≤ 10 (`GUILD_MAX`), нужен ник; название 3–24, уникально по `nameKey`; код — 8 символов `CODE_ALPHABET` (как код друга).
- Видимость — как друзьям: `shareActivity` и `hideWeights` действуют в ленте гильдии (веса срезаются на сервере).
- Уведомления — `NotificationType.SOCIAL`.
- Запросы в транзакции — по очереди; гонка за последнее место — `SELECT … FOR UPDATE` строки `Guild`.
- Миграция: `migrate dev --create-only`, проверить SQL на `DROP INDEX` частичных индексов, затем применить. Если дев-база расходится — `migrate deploy` (не reset).
- Тексты: «Гильдия», «Создать гильдию», «Вступить по коду», «Название», «Значок», «Вступить в гильдию «…»?», «Вступить», «Вы выйдете из «…»», «В гильдии нет мест», «Такая гильдия уже есть», «Сначала передайте главенство», «Выйти из гильдии», «Исключить», «Сделать главой», «Сменить ссылку», «Пригласить», «Состав», «Лента гильдии», «глава», «Нужен ник».

## Review Focus

- Двое одновременно занимают последнее место — 11-го не будет. → `FOR UPDATE` в `joinGuildAction` (ревью; e2e не воспроизводит гонку).
- Не глава вызывает `kickMemberAction`/`transferLeadAction`/`regenerateGuildCodeAction` напрямую — отказ. → код Task 2 (ревью).
- Глава исключает сам себя / передаёт главенство не участнику — отказ. → код Task 2.
- Тренировка согильдийца с `shareActivity = false` не видна в ленте гильдии и 👊 на неё не ставится. → Task 3 (`feedAuthorIds`/`canSeeWorkout` для гильдии с тем же фильтром).
- Вступление в другую гильдию, будучи главой текущей с участниками, — отказ «Сначала передайте главенство» (иначе гильдия без главы). → `joinBlock` unit + код Task 2.

// same — уже в этой; leader — глава другой гильдии с участниками; full — members >= GUILD_MAX
