# Замена упражнения в тренировке («тренажёр занят»)

Дата: 2026-10-18. Релиз: `release/2026-12-next`. Без фича-флага.

## Зачем

В зале тренажёр занят — человек хочет за 1–2 тапа заменить упражнение на похожее прямо из карточки упражнения, не теряя темпа. Сейчас замена есть только в чате «Помощника» (флаг `smart_coach`, 3 шага).

## Решения

- Замена действует **только на эту тренировку**: шаблон, программа, задания тренера и своя прогрессия не меняются. В следующий раз — снова исходное упражнение.
- Доступна всем, без флага.
- Пометки «вместо …» в сохранённой тренировке нет (не нужна миграция и правка синхронизации; можно добавить позже).

## Поведение

1. Меню «⋯» упражнения в тренировке (`components/training/exercise-block.tsx`): новый пункт **«Заменить»** между «Ниже» и «Удалить». Показывается у любого упражнения, в том числе выполненного частично.
2. Открывается диалог (`components/ui/dialog`, как остальные диалоги тренировки) «Заменить: <название>» с подзаголовком «Тренажёр занят? Похожие упражнения»:
   - до 3 кандидатов — кнопки с названием и прошлым результатом («в прошлый раз 3 × 10 · 60 кг», без истории — «ещё не делали»);
   - если подходы уже начаты — подсказка «Сделанные подходы останутся, новое упражнение встанет следом»;
   - **«Другое упражнение…»** — выбор из всего каталога (поиск + фильтр групп) с фильтром по основной группе текущего упражнения, фильтр можно снять; выбор одного упражнения сразу заменяет;
   - кандидатов нет — «Похожих упражнений нет» и кнопки «Другое упражнение…» и «Пропустить сегодня» (существующее `skipPending`).
3. Замена:
   - подходов ещё не было — упражнение заменяется на месте;
   - подходы начаты — исходное остаётся с выполненными подходами, новое вставляется сразу после него (невыполненные подходы исходного не трогаются — как в помощнике);
   - новое остаётся в том же суперсете;
   - подходы, вес и повторы — из прошлого раза нового упражнения (как при добавлении), отдых — `defaultRestSec`.
4. Тост «Заменено: <новое>» с кнопкой **«Вернуть»**: новое убирается, исходное возвращается на своё место (если было заменено на месте). Фокус после замены — на заголовок нового упражнения.

## Подбор кандидатов

Существующая `replacementCandidates` (`lib/assistant/rules.ts`) — общая для помощника и меню:
- та же основная группа мышц (`muscleGroups[0]`), тот же вид (`kind`), не архивное, не уже в тренировке, не болевая зона;
- сначала делавшиеся за 90 дней (свежие выше), затем встроенные; максимум 3.

Данные уже есть в редакторе: каталог — проп `exercises`, даты — из `last` (`LastPerformance` грузится для всего каталога в `app/(app)/training/page.tsx`), болевые зоны — `readPain(workoutId)` из `components/assistant/pain-store` (без чек-ина — пусто). Сервер не нужен — работает и без сети.

## Редьюсер (`components/training/workout-state.ts`)

- `replaceExercise` получает необязательный `newKey` — ключ нового упражнения задаёт вызывающий (нужен для «Вернуть»). Без `newKey` — как сейчас (помощник).
- Новое действие `undoReplace { newKey, original: ExerciseState }`: убирает упражнение `newKey`; если `original.key` в тренировке нет (заменено на месте) — вставляет `original` на позицию убранного. Нет `newKey` в состоянии (уже удалили) — ничего не делает. Входит в `GROUPING` (перенормировка суперсетов).
- Помощник переходит на тот же вызов (с `newKey` не обязательно).

## Прогрессия и данные

- Исходное упражнение без выполненных подходов попыткой не считается: `applyOwnProgression` пропускает отсутствующее, `progressTarget` без подходов возвращает `null` (прогрессия тренера). Так уже работает — проверить тестом.
- Программа (вес недели) — по исходному упражнению не применяется к замене; у замены вес из прошлого раза.
- Новых таблиц, полей и связей с `User` нет — «Мои данные» и удаление аккаунта не затрагиваются.

## Компоненты

- `components/training/exercise-swap-dialog.tsx` (новый): диалог замены — кандидаты, «Другое упражнение…» (переиспользует `ExerciseFilterControls`/`useExerciseFilter` с начальной группой), пустое состояние.
- `useExerciseFilter(exercises, initialGroup?)` — необязательная начальная группа.
- `exercise-block.tsx` — пункт меню и открытие диалога; `workout-editor.tsx` — прокидывает каталог, `last`, болевые зоны и обработчик замены (dispatch + тост).

## Ошибки и края

- Упражнение удалили, пока открыт диалог — замена ничего не делает (`replaceExercise` с неизвестным ключом возвращает то же состояние), диалог закрывается.
- «Вернуть» после последующих правок — работает по ключам, не по индексам; если исходное уже удалено пользователем — возвращается на позицию нового.
- Кардио/на время — кандидаты того же вида; поля длительности/дистанции нового упражнения — из прошлого раза.
