# Растяжка

Дата: 2026-10-28. Под фича-флагом `stretching` (по умолчанию выключен).

## Цель

Дать растяжке своё место в Hero Fit: каталог упражнений по зонам, отдельный раздел в меню, короткие сессии растяжки и заминка в силовой тренировке, цели — регулярность, время удержания и навыки вроде шпагата. Растяжка поощряется XP, но не подменяет силовые тренировки в игровых механиках.

Вне этапа: назначения растяжки от тренера, отдельные ачивки за растяжку, раздельный учёт левой и правой стороны, видео и анимации упражнений.

## Принципы

- Растяжка — новый вид упражнения `ExerciseKind.STRETCH`, подход — время удержания (`WorkoutSet.durationSec`, `reps = 0`, `weight = 0`), как у упражнений на время. Отдельной модели сессии нет: сессия растяжки — обычная `Workout`, где все выполненные упражнения — растяжка. Редактор, офлайн, черновики, шаблоны, календарь, история, таймер отдыха — без изменений.
- Растяжку можно смешивать с силовыми (заминка) — такая тренировка остаётся силовой.
- Силовые механики растяжку не видят: объём, 1ПМ, «Пора увеличить вес», силовое «точно столько?», прогрессия, помощник, карта мышц, восстановление мышц, баланс нагрузки.
- Сессия растяжки не двигает игру: серию недель, босса, рейды, лигу, рейтинг, задания клуба, ачивки и цели по числу тренировок и часам.

## Флаг `stretching`

Ключ в `lib/flags/registry.ts`. Без флага:
- упражнения `STRETCH` (встроенные и свои) скрыты в каталоге `/exercises`, `ExercisePicker`, `ExerciseCatalog`, кандидатах замены (`listExercises` и соседи — как кардио без `workout_formats`);
- нет пункта меню, `/stretching` — 404;
- в форме упражнения нет вида «Растяжка», в диалоге цели — типов растяжки;
- история, сводки, статистика и уже поставленные цели показывают всё как есть (выключение флага ничего не теряет).

Пункт «Что нового» про растяжку — с `flag: "stretching"`. e2e с глобальным флагом — `mode: "serial"`, только desktop; остальные включают флаг пользователю (`userIds`).

## Данные

```prisma
enum ExerciseKind { REPS TIME CARDIO STRETCH }

enum StretchZone {
  NECK        // шея
  SHOULDERS   // плечи
  CHEST       // грудь
  BACK        // спина
  LOWER_BACK  // поясница
  HIPS        // тазобедренные
  HAMSTRINGS  // задняя поверхность бедра
  QUADS       // передняя поверхность бедра
  ADDUCTORS   // приводящие
  CALVES      // икры
}

model Exercise {
  // …
  stretchZones StretchZone[] @default([])  // только у STRETCH; первая — основная
  perSide      Boolean       @default(false) // одностороннее: подход = каждая сторона
}

model Workout {
  // …
  stretchOnly Boolean @default(false) // ставится при завершении: все выполненные упражнения — STRETCH
}

enum GoalType { STRENGTH WORKOUTS STREAK HOURS BODY_WEIGHT STRETCH_WEEKLY STRETCH_HOLD STRETCH_SKILL }
enum StretchUnit { SESSIONS MINUTES }

model Goal {
  // …
  stretchUnit  StretchUnit? // только STRETCH_WEEKLY
  stretchSkill String?      // только STRETCH_SKILL: ключ навыка или null у своего
  skillTitle   String?      // только STRETCH_SKILL: название своего навыка (до 60 символов)
}

model StretchMeasurement {
  id     String   @id @default(cuid())
  userId String
  goalId String
  date   String   // местный день "YYYY-MM-DD"
  cm     Decimal  @db.Decimal(5, 1) // 0…200, «см до цели»
  createdAt DateTime @default(now())
  user User @relation(fields: [userId], references: [id], onDelete: Cascade)
  goal Goal @relation(fields: [goalId], references: [id], onDelete: Cascade)
  @@unique([goalId, date])
  @@index([userId])
}
```

У упражнения `STRETCH` `muscleGroups` пустой (валидация формы и сид), у остальных видов `stretchZones` пустой. Замер привязан к цели: новая цель по тому же навыку начинается со своего стартового замера.

Новая связь с `User` (`StretchMeasurement`) — проверить удаление аккаунта и «Мои данные» (`lib/account/*`, `e2e/account-data.spec.ts`): раздел `stretchMeasurements` (навык, дата, см), у упражнений — `kind`, `stretchZones`, `perSide`, у целей — новые поля.

## Каталог и сид

- Зоны — `lib/stretching/zones.ts`: порядок, подписи («Шея», «Плечи», «Грудь», «Спина», «Поясница», «Тазобедренные», «Задняя поверхность бедра», «Передняя поверхность бедра», «Приводящие», «Икры»), иконка/цвет — семантические токены.
- Сид (`prisma/seed.ts`, тип `SeedExercise` — `kind: "STRETCH"`, `zones`, `perSide`): ~20 встроенных упражнений, минимум одно на зону — наклоны головы, растяжка плеча у груди, растяжка груди в проёме, кошка-корова, поза ребёнка, кобра, складка стоя, складка сидя, бабочка, лягушка, выпад на сгибатели бедра, голубь, растяжка квадрицепса стоя, растяжка икры у стены и др.; отдых по умолчанию 15 с.
- Готовые программы (`userId = null`): «Утренняя растяжка» (~10 мин) и «Заминка после силовой» (~8 мин). Без флага они скрыты там же, где показываются программы (шаблоны, где все упражнения — растяжка).
- Своё упражнение: в `exercise-form-dialog` при флаге — вид «Растяжка»; вместо групп мышц — выбор зон (минимум одна), галочка «Одностороннее (каждая сторона)». Сменить вид нельзя, если есть подходы (правило `lib/exercises/actions.ts` уже есть).
- `/exercises` при флаге — фильтр-чип «Растяжка»; упражнения растяжки сгруппированы по основной зоне.

## Меню и страница `/stretching`

- `STRETCH_NAV_ITEM` в `components/app/nav.ts` (иконка Lucide `StretchHorizontal` или подходящая), вставка после «Упражнений» по `useFlag("stretching")` в `nav-links.tsx`; на телефоне — в меню профиля, нижняя панель не меняется.
- Страница (`app/(app)/stretching/page.tsx`, флаг проверяется на сервере → `notFound()`):
  1. **Шапка**: кнопка «Начать растяжку» (выбор: готовая программа / свой шаблон из растяжки / «Пустая — выберу упражнения» → `createWorkoutAction`), цифры недели — минут растяжки и сессий (в поясе пользователя, с понедельника).
  2. **Цели по растяжке**: карточки активных целей трёх новых типов (`GoalCard`), «Поставить цель» — `NewGoal` с предвыбранной вкладкой «Растяжка».
  3. **Каталог**: упражнения растяжки по зонам, ★ избранного, рекорд удержания у сделанных.
- Если активная тренировка уже идёт — «Начать растяжку» ведёт в неё (как кнопка на дашборде), упражнения добавляются там.

## Тренировка

- Ввод подхода `STRETCH` — поле «Время» (`parseClock`, голое число — секунды, как у `TIME`), у односторонних подпись «каждая сторона» и в тексте подхода «30 с × 2».
- **Кнопка ▶ «Держать»** у невыполненного подхода растяжки: обратный отсчёт удержания — время, введённое в подходе, иначе прошлого подхода этого упражнения, иначе 30 с. У одностороннего — два отсчёта подряд с паузой 5 с и тостом «Другая сторона». В конце — звук + вибрация (+ уведомление, если вкладка в фоне — механизм таймера отдыха), подход отмечается выполненным с этим временем, дальше обычный таймер отдыха. «Стоп» — отмечает фактически удержанное время (от 5 с), отмена — без отметки. Логика отсчёта — чистые функции `lib/stretching/hold.ts`.
- `lib/workouts/kinds.ts`: `isTimed` включает `STRETCH`; `timedSetText` — «45 с» / «1:30 × 2»; `isDoneSet` не меняется (время > 0).
- `workoutTotals`: новое `stretchSec` (сумма удержаний, у `perSide` ×2), `workSec` растяжку не включает.
- Замена упражнения, помощник, прогрессия, разминка и калькулятор блинов — растяжку не предлагают и не трогают; кандидаты замены у растяжки — та же основная зона.

## XP, рекорды, игра

- Завершение (`lib/workouts/finish.ts`): `stretchOnly = есть выполненные подходы и все выполненные упражнения — STRETCH`.
- XP (`lib/progress/xp.ts`):
  - сессия растяжки: `15 + минуты удержания` (округление вниз), максимум 60, причина `XpReason.STRETCH_SESSION`; + 25 за побитый рекорд по общему правилу;
  - растяжка в силовой: +1 XP за минуту удержания (как `workSec` сейчас), в общем лимите 600.
- Рекорды: `MAX_DURATION` по каждому упражнению растяжки (`bestOfTimed`), первый результат — PR без бонуса.
- Сессия растяжки **не** участвует: `countWeekWorkouts` и `applyWeekCredit` (серия), напоминание «Не потеряй streak!», босс недели, рейды, лига друзей и рейтинг (XP `STRETCH_SESSION` в лигу не идёт), задания клуба, ачивки по числу тренировок и подходов, цели `WORKOUTS`/`HOURS`, итоги недели (кроме строки «Растяжка: N мин»). Ежедневный сундук работает как раньше (он от входа, не от тренировок). Все места, считающие тренировки, получают условие `stretchOnly = false` — список собирается в плане по поиску `status: "COMPLETED"`/`'COMPLETED'`.
- Лента друзей: сессия растяжки — запись «Растяжка · 12 мин» (без объёма и повторов), силовая с заминкой — как обычно.
- Сводка сессии растяжки: время, минуты удержания, упражнения, рекорды, цели, XP; без объёма, повторов, босса и серии. Сторис и карточка рекорда работают (рекорд удержания — «1:30»).

## Статистика

- `/stats` при флаге (или при наличии растяжки в истории) — блок «Растяжка»: минуты и сессии за 7/30 дней, топ-3 зоны по минутам. SQL — по `e.kind = 'STRETCH'` в поясе пользователя (`lib/stats/queries.ts`).
- Блок «Кардио» исключает `STRETCH`; счётчики «тренировок всего/за месяц/за неделю» и часы в зале — без сессий растяжки.
- Страница упражнения растяжки — рекорд и график времени удержания (как у `TIME`).
- CSV — колонка «Время, с» уже есть; `kind` — «STRETCH».

## Цели

Встраиваются в `/goals` и общие правила (`lib/goals/rules.ts`): лимит 5 активных на все типы, срок, сундук 100 XP, ачивки «Целеустремлённый», напоминание за 7 дней, «Поставить снова». В `NewGoal` — группа «Растяжка» с тремя типами (только при флаге).

### Регулярность — `STRETCH_WEEKLY`

- Поля: `stretchUnit` (`SESSIONS` | `MINUTES`), `target` — норма в неделю (сессий 1…7, минут 5…300), длительность — 2…12 недель. Срок (`deadline`) — воскресенье последней недели; первая неделя — текущая, если до её конца ≥ 4 дней (постановка пн…чт), иначе следующая. Новое поле не нужно: недели цели выводятся из `createdAt` и `deadline` в поясе пользователя чистой `stretchWeeks(goal, tz)`.
- Неделя засчитана, если норма выполнена: сессии — тренировки с хотя бы одним выполненным подходом растяжки (включая заминку в силовой); минуты — сумма `stretchSec`.
- Прогресс — «засчитано недель / всего», в карточке ещё «эта неделя: 1/3».
- Достигнута — когда засчитана последняя неделя (при завершении тренировки, `applyGoals`). Провал — тик после конца недели, в которой норма не выполнена (`GOAL_FAIL_GRACE_MS` как у срока): уведомление «Неделя без растяжки — цель «…» не выполнена» и «Поставить снова».
- Логика — чистые `lib/goals/stretch-weekly.ts` (`stretchWeeks`, `weekDone`, `weeklyStatus`), данные — `getCurrentValues` (суммы по неделям одним запросом).

### Удержание — `STRETCH_HOLD`

- Упражнение `STRETCH` + целевое время (10 с…10 мин); прогресс — `PersonalRecord` `MAX_DURATION`, старт — текущий рекорд (если уже ≥ цели — «Уже достигнуто», как у силовой).
- Выполнение — при завершении тренировки (`applyGoals`), блок «Цели» в сводке. Прогноз — `forecastGoal` по неделям рекорда удержания.

### Навык — `STRETCH_SKILL`

- Навыки (`lib/stretching/skills.ts`): `SPLIT_LEFT` «Продольный шпагат (левая впереди)», `SPLIT_RIGHT` «Продольный шпагат (правая впереди)», `SPLIT_SIDE` «Поперечный шпагат», `FOLD_STANDING` «Ладони в пол в наклоне», `FOLD_SEATED` «Лоб к коленям сидя», `BRIDGE` «Мостик»; у каждого — подсказка, что мерить («см от паха до пола», «см от ладоней до пола» …). Свой навык — название до 60 символов, мерка — «см до цели».
- При постановке — стартовый замер (> 0, до 200 см, шаг 0,5); цель — 0 см. Активная цель по одному навыку — одна.
- «Записать замер» на карточке цели (`GoalCard`, на `/goals` и `/stretching`): один замер в местный день (повтор за день — заменяет). Значение — последний замер. График замеров (как вес тела, 90 дней), прогноз — `forecastGoal` (ниже — лучше).
- Достигнута при замере 0 — сразу (уведомление `GOAL`, сундук). Подсказка в карточке: «Замеряйте раз в неделю в одно и то же время после разминки».
- Действие — `logStretchMeasurementAction` (`lib/goals/stretch-actions.ts`), валидация — Zod.

## Тексты

Человеческим языком, без «STRETCH»: вид «Растяжка», «Держать», «Другая сторона», «каждая сторона», «Удержание: 1:30», «2 из 4 недель», «Записать замер», «Осталось 12 см».

## Тестирование

- Unit: `lib/stretching/hold.ts`, `skills.ts`, `zones.ts`; `kinds.ts` (`STRETCH`); `workoutTotals` (`stretchSec`, ×2); `workoutXp` (сессия растяжки — 15 + мин, ≤ 60; смешанная); `stretchOnly`; `lib/goals/stretch-weekly.ts` (неделя старта, засчёт, провал); `rules.ts` — схемы и тексты новых типов, `canCreate` (навык один); registry флага.
- e2e (`e2e/stretching.spec.ts`, флаг пользователю через `userIds`):
  - без флага — нет пункта меню, `/stretching` 404, растяжки нет в каталоге;
  - пункт меню, `/stretching`, «Начать растяжку» из программы → «Держать» (короткий отсчёт с тестовым временем), завершение → сводка «Растяжка», XP ≤ 60, рекорд удержания;

  - своё упражнение растяжки с зонами и «одностороннее»;
  - «Мои данные» содержат замеры, удаление аккаунта — без ошибок.
