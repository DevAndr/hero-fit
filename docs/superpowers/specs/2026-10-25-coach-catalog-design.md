# Каталог тренеров и контакты тренера

Дата: 2026-10-25. Флаг: `coach_catalog`. Продолжение публичной страницы тренера (`2026-10-10-coach-public-page-design.md`, где каталог и контакты были «вне этапа»).

## Цель

Пользователь находит тренера в каталоге `/trainers` (фильтры: город, формат, специализация) и связывается с ним напрямую по контактам, которые тренер сам указал. Заявок через приложение, переписки и модерации контактов нет.

Успех: тренер с опубликованной страницей, контактом, согласием и включённым переключателем «Показывать меня в каталоге» виден в каталоге; вошедший пользователь открывает контакт в один клик; тренер видит, сколько раз открывали его контакты.

Вне этапа: заявки/сообщения через приложение, отзывы и оценки, фото, свободные ссылки на сайты и соцсети, поиск по имени, карта, тренеры клуба на странице зала.

## Данные

`CoachProfile` — новые необязательные колонки:

- `telegram String?` — ник без `@`;
- `whatsapp String?` — номер в виде `+79991234567`;
- `vk String?` — короткое имя или `id123`;
- `phone String?` — номер в виде `+79991234567`;
- `email String?`;
- `contactsConsentAt DateTime?` — согласие показывать контакты вошедшим пользователям;
- `catalogListed Boolean @default(false)` — тренер сам включил «Показывать меня в каталоге тренеров» (по умолчанию выключено: опубликованная страница сама в каталог не попадает).

Новая модель — счётчик открытий контактов по дням (кто открывал, не хранится):

```prisma
model CoachContactClick {
  coachId String
  day     DateTime @db.Date
  count   Int      @default(0)
  coach   User     @relation(fields: [coachId], references: [id], onDelete: Cascade)

  @@id([coachId, day])
}
```

## Правила (чистые функции)

`lib/coach/contacts.ts`:

- `contactsSchema` (Zod) с нормализацией:
  - Telegram: принимает `@nick`, `nick`, `t.me/nick`, `https://t.me/nick`; хранит `nick`; 5–32 символа `[A-Za-z0-9_]`;
  - WhatsApp и телефон: принимает `8…`, `+7…`, пробелы, скобки, дефисы; `8` в начале 11-значного номера → `+7`; хранит `+` и 10–15 цифр;
  - VK: принимает `vk.com/name`, `https://vk.com/name`, `name`, `id123`; хранит короткое имя (`[A-Za-z0-9_.]`, 2–32);
  - email: `z.email()`, до 254 знаков;
  - пустая строка → `null`.
- `contactLinks(profile)` — список `{ kind, label, href }` только из нормализованных значений: `https://t.me/<nick>`, `https://wa.me/<цифры>`, `https://vk.com/<name>`, `tel:+…`, `mailto:…`. Своих URL нет.
- `hasContacts(profile)` — есть хотя бы один контакт.
- `inCatalog(profile, isCoach)` — `catalogListed`, `publishedAt` и `isCoach`, `hasContacts`, `contactsConsentAt`, и указан город или формат `ONLINE`.
- `catalogMissing(profile, isCoach)` — что мешает попасть в каталог (для подсказки в редакторе): «включите показ в каталоге», «опубликуйте страницу», «укажите хотя бы один контакт», «отметьте согласие на показ контактов», «укажите город».

`lib/coach/catalog.ts`:

- `catalogFilterSchema` — `city` (строка, сравнение по `lower(trim())`), `format` (`ONLINE` | `OFFLINE` | пусто), `specialty` (код из `SPECIALTIES`), `page` (≥ 1). Неизвестные значения игнорируются.
- `matchesFormat(coachFormat, wanted)` — `BOTH` подходит под оба формата.
- `sortCatalog(coaches, day)` — сначала активные (вход за последние 14 дней по `UserVisit` и хотя бы один активный клиент или опубликованная программа), затем остальные; внутри каждой группы — стабильное перемешивание по хешу `userId + day` (дата дня в UTC — порядок меняется раз в сутки и одинаков у всех).
- `CATALOG_PAGE_SIZE = 20`, `ACTIVE_DAYS = 14`, `ABOUT_PREVIEW = 140`.

## Редактор `/coach/page`

Новый блок «Контакты»: пять полей (Telegram, WhatsApp, VK, телефон, email) и галочка «Показывать контакты вошедшим пользователям Hero Fit». Отметка ставит `contactsConsentAt = now()` (если ещё не стоит), снятие — `null`. Без согласия контакты хранятся, но нигде не показываются. Сохранение — тем же действием, что и профиль (схема профиля расширяется `contactsSchema`).

С флагом — переключатель «Показывать меня в каталоге тренеров» (`catalogListed`, по умолчанию выключен; включить можно в любой момент, сохраняется вместе с профилем; снятие публикации страницы или режима тренера убирает из каталога без сброса переключателя) и строка статуса: «В каталоге тренеров» со ссылкой на `/trainers` или «Не в каталоге: …» (`catalogMissing`), и «Контакты открывали N раз за 30 дней».

## Каталог `/trainers`

- Группа `app/(marketing)/`, публичная (`PUBLIC_PAGES` в `proxy.ts`), в `sitemap.xml`, индексируется (`force-dynamic` — флаг читается при запросе). Без флага `coach_catalog` (глобально) — 404 всем.
- Заголовок «Тренеры Hero Fit», фильтры — GET-форма (query-параметры, ссылки с фильтром можно отправить): город — `select` из городов тренеров каталога (по `lower(trim(city))`, показывается первое написание), формат, специализация. Кнопка «Сбросить».
- Выборка — `getCatalog(filter, day)` в `lib/coach/catalog-queries.ts`: профили по условию `inCatalog` в SQL (Prisma `where`), фильтры, затем `sortCatalog` и страница. Число тренеров каталога невелико — сортировка в памяти допустима; при росте — пересмотреть.
- Карточка: имя (`displayName` или ник), ник, город, формат (`FORMAT_LABELS`), до 4 специализаций, первые 140 знаков «О себе», блок контактов, ссылка «Подробнее» → `/trainer/<ник>`.
- Пустое состояние: «По этим условиям тренеров пока нет» + «Сбросить фильтры».
- Пагинация — «Назад» / «Дальше» по 20.

## Контакты на странице и в каталоге

Общий компонент `CoachContacts` (`components/coach/coach-contacts.tsx`):

- Вошедшему (`getUser()` не null) — кнопки-ссылки `contactLinks` (`target="_blank"`, `rel="noopener noreferrer nofollow"`), клик вызывает `contactClickAction(coachId)` (без ожидания).
- Гостю — «Войдите, чтобы увидеть контакты» → `/login?next=<текущий путь>`. Контакты гостю в HTML не попадают (решение на сервере), в JSON-LD (`coachJsonLd`) их нет.
- На `/trainer/<ник>` блок показывается рядом с «Заниматься» при согласии и хотя бы одном контакте — независимо от того, попал ли тренер в каталог. Флаг: блок контактов на странице тренера — тоже только с `coach_catalog`.

`contactClickAction(coachId)` (`lib/coach/catalog-actions.ts`): требует вход (`requireUser`), бот по `isBot` (user-agent) и клик тренера по своим контактам не считаются; тренер должен быть `inCatalog` или иметь видимые контакты; `upsert` по `(coachId, день)` с `count + 1`. Цель метрики `trainer_contact_click`.

## Точки входа (все под флагом)

- Меню приложения — пункт «Найти тренера» (`components/app/nav.ts`, как `PROGRAMS_NAV_ITEM`, `mobile: false`).
- `/settings`: когда тренера нет — строка «Найти тренера в каталоге» со ссылкой на `/trainers` (сейчас блок «Мой тренер» есть только при связи).
- Лендинг: ссылка «Тренеры» в шапке и подвале, пункт FAQ «Как найти тренера?» — только при включённом флаге.
- Админка, «Фичи»: строка «Каталог тренеров» — тренеров в каталоге, открытий контактов за 7/30 дней.

## 152-ФЗ, «Мои данные», удаление

- Контакты — данные тренера, публикуются им самим по отметке согласия; видны только вошедшим пользователям.
- «Мои данные»: в раздел профиля тренера — контакты, `contactsConsentAt`, `catalogListed`, открытия контактов по дням (`day`, `count`).
- Удаление аккаунта: профиль и `CoachContactClick` уходят каскадом.
- `/privacy`: «Если тренер указал контакты и согласился их показывать, их видят вошедшие пользователи Hero Fit. Тренер видит только число открытий своих контактов».

## Тесты

Unit: `contactsSchema` (все варианты ввода и ошибки), `contactLinks`, `inCatalog` (в т.ч. выключенный `catalogListed`), `catalogMissing`, `matchesFormat`, `sortCatalog` (активные выше, стабильность в пределах дня, смена порядка в другой день), `catalogFilterSchema`.

e2e `e2e/coach-catalog.spec.ts` (флаг глобальный — `mode: "serial"`, только desktop; отдельный проект после соседних с глобальными флагами, если понадобится):

- тренер с опубликованной страницей, контактами и согласием, но с выключенным переключателем — нет в каталоге, подсказка «включите показ в каталоге»;
- тренер включает переключатель → «В каталоге тренеров», он виден в `/trainers`; выключает — пропадает;
- без согласия или без контакта — нет в каталоге, подсказка в редакторе;
- гость: «Войдите, чтобы увидеть контакты», номера телефона нет в HTML каталога и страницы тренера;
- вошедший видит ссылки; клик увеличивает счётчик, у тренера «открывали 1 раз»;
- фильтры по городу, формату (`BOTH` под оба) и специализации;
- без флага `/trainers` — 404, пункта меню нет;
- «Мои данные» содержат контакты; удаление аккаунта тренера убирает его из каталога.
