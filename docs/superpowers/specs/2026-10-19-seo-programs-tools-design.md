# SEO: публичные страницы программ и новые калькуляторы

## Цель

Сейчас у поисковиков есть лендинг, два калькулятора, страницы тренеров и залов. Добавляем страницы под частые запросы,
которые сразу ведут в продукт:

- пять публичных страниц программ тренировок («программа 5×5», «push pull legs», «верх низ», «программа для новичка
  в зале», «full body») и общую страницу программ; кнопка «Начать программу» — один шаг от поиска до первой тренировки;
- калькуляторы «DOTS и Wilks» и «Разминочные подходы».

Успех: страницы индексируются (sitemap, canonical, JSON-LD), открываются без входа, «Начать программу» приводит гостя
через регистрацию прямо в редактор первого дня, а вошедшего — сразу; Метрика считает цель `program_start`.

## Решения

- **Один источник программ:** модуль `lib/programs/builtin.ts` — и для сида, и для страниц. Список `PROGRAMS` в
  `prisma/seed.ts` удаляется, сид берёт дни отсюда (поиск существующих шаблонов — как сейчас, по `userId = null`,
  `program`, `name`: имена существующих дней и программ не меняются, иначе на проде появятся дубли).
- **Адреса:** `/programs` занят закрытым каталогом программ тренеров, поэтому публичные — `/training-programs` и
  `/training-programs/<slug>`.
- **Страницы статические** — данные из модуля, без БД.
- **Без фича-флага:** публичные страницы, нерискованные.
- **Утверждения в текстах** — только о том, что есть в приложении («Пора увеличить вес», таймер отдыха, разминка
  одной кнопкой, калькулятор блинов, расчётный 1ПМ).

- **Верх:** Жим штанги лёжа 4×6, Тяга штанги в наклоне 4×8, Жим штанги стоя 3×8, Тяга верхнего блока 3×10, Подъём

- **Низ:** Приседания со штангой 4×6, Румынская тяга 3×8, Жим ногами 3×10, Выпады с гантелями 3×10, Подъём на носки
  стоя 4×12, Подъём ног в висе 3×12. Описание: «Ноги, икры, пресс».
- **Новичок — день A:** Приседания со штангой 3×10, Жим штанги лёжа 3×10, Тяга верхнего блока 3×12, Скручивания

  Описание: «Ноги, плечи, спина, икры».

### Модуль `lib/programs/builtin.ts`

```ts
export type BuiltinDay = { name: string; description: string; exercises: [name: string, sets: number, reps: number][] };
export type BuiltinProgram = {
  slug: string;
  program: string;           // поле WorkoutTemplate.program
  title: string;             // h1 и основа <title>
  metaTitle: string;         // <title> под запрос
  description: string;       // meta description, ≤ 160 символов
  level: "Начальный" | "Средний" | "Начальный и средний";
  perWeek: string;           // «3 раза в неделю»
  intro: string;             // 2–3 предложения: что это и кому
  forWhom: string[];         // 3–4 пункта
  schedule: string[];        // расписание недели: «Пн — Push», …
  progression: string;       // как прибавлять вес (с упоминанием «Пора увеличить вес»)
  faq: { q: string; a: string }[]; // 4–5
  days: BuiltinDay[];        // первый — день старта
};
export const BUILTIN_PROGRAMS: BuiltinProgram[];
export function programBySlug(slug: string): BuiltinProgram | null;
```

Тексты пишутся в задаче реализации по этой спеке; заголовки:

- Push / Pull / Legs — «Программа тренировок Push Pull Legs (сплит Тяни-Толкай-Ноги)»
- Full Body — «Программа Full Body: тренировка всего тела»
- 5×5 — «Программа 5×5 для силы»
- Верх / Низ — «Программа Верх / Низ (Upper/Lower сплит) на 4 дня»
- Для новичка — «Программа тренировок для новичка в зале»

FAQ — живые вопросы запроса: сколько раз в неделю, сколько отдыхать между подходами, как прибавлять вес, можно ли
девушкам, что делать при застое, через сколько менять программу. Ответы — без медицинских обещаний.

## Страницы программ

- `/training-programs` — `h1` «Программы тренировок в зал», вступление, карточки пяти программ (уровень, раз в неделю,
  дни), ссылки на калькуляторы. JSON-LD: `BreadcrumbList`, `ItemList`.
- `/training-programs/<slug>` (`generateStaticParams` по `BUILTIN_PROGRAMS`, неизвестный slug — 404): хлебные крошки,
  `h1`, вступление, плашки «уровень · раз в неделю · дней», «Для кого», «Расписание недели», дни (название, описание,
  таблица упражнение / подходы × повторы), «Как прибавлять вес», кнопка «Начать программу», FAQ, «Другие программы»,
  ссылки на калькуляторы 1ПМ и разминки. JSON-LD: `BreadcrumbList`, `ExercisePlan` (name, description,
  `activityFrequency`, `exerciseType: "Силовые тренировки"`), `FAQPage`.
- Метаданные: `title` = `metaTitle`, `description`, `alternates.canonical`, `openGraph` (title, description, url).
- Оформление — как у калькуляторов (`app/(marketing)/tools/*`): шрифт заголовков `font-display`, семантические токены.

## «Начать программу»

Обработчик `GET /training-programs/[slug]/start` (по образцу `app/(marketing)/trainer/[nick]/join/route.ts`):

1. Неизвестный slug → 404.
2. `queueGoal("program_start")`.
3. Гость → `redirect("/register?next=/training-programs/<slug>/start")` (после регистрации — снова сюда, уже с сессией).
4. Есть активная тренировка (`ACTIVE_STATUSES`) → `/training`.
5. Иначе — встроенный шаблон первого дня (`userId = null`, `program`, `name = days[0].name`); нет такого → `/training`.
   Создать тренировку в статусе PLANNED тем же кодом, что `createWorkoutAction` для `source = "template:<id>"`
   (общая функция `createPlannedWorkout(userId, source)` в `lib/workouts/`; `createWorkoutAction` вызывает её) и
   `redirect("/training")`.

Ссылка — обычный `<a href>` (как у «Заниматься» тренера), не `Link` (без префетча обработчика). Цель
`program_start` добавляется в список целей Метрики (`lib/analytics/goals.ts`) и в `deploy/README.md`.

## Калькуляторы

### `/tools/dots-wilks` — «Калькулятор DOTS и Wilks»

Ввод: пол (мужчина/женщина), вес тела (кг), присед, жим лёжа, становая (кг; пустое = 0) или переключатель «только
сумма». Вывод: сумма, DOTS, Wilks (по 2 знака), уровень по DOTS: < 200 «Начинающий», 200–299 «Любитель»,
300–399 «Продвинутый», 400–499 «Мастер», ≥ 500 «Элита» — с пометкой «шкала ориентировочная».

`lib/progress/strength-score.ts` (чистые функции): `dots(total, bodyweight, sex)`, `wilks(total, bodyweight, sex)`,
`dotsLevel(score)`; `sex: "male" | "female"`. Вес тела ограничивается: DOTS — 40…210 (м) / 40…150 (ж); Wilks —
40…201.9 (м) / 26.51…154.53 (ж). Формула: `total × 500 / полином(bw)`.

- DOTS, мужчины: a = −307.75076, b = 24.0900756, c = −0.1918759221, d = 0.0007391293, e = −0.000001093;
  женщины: a = −57.96288, b = 13.6175032, c = −0.1126655495, d = 0.0005158568, e = −0.0000010706
  (полином a + b·x + c·x² + d·x³ + e·x⁴).
- Wilks (классический), мужчины: a = −216.0475144, b = 16.2606339, c = −0.002388645, d = −0.00113732,
  e = 7.01863e−6, f = −1.291e−8; женщины: a = 594.31747775582, b = −27.23842536447, c = 0.82112226871,
  d = −0.00930733913, e = 4.731582e−5, f = −9.054e−8 (полином до x⁵).
- Опорные значения (тест, ±0.01): м 600/100 → DOTS 369.31, Wilks 365.15; м 500/80 → 344.77 / 341.35;
  ж 300/60 → 332.56 / 334.47; ж 400/70 → 404.50 / 397.94.

Текст и FAQ: что такое DOTS и Wilks и чем отличаются, какой результат хороший для моего веса, где взять максимум
(ссылка на калькулятор 1ПМ), «Hero Fit считает расчётный 1ПМ по каждому упражнению».

### `/tools/warmup` — «Калькулятор разминочных подходов»

Ввод: рабочий вес (кг), гриф 20 / 15 / 10 кг. Вывод: подходы `warmupSets(work, bar)` (`lib/progress/plates.ts`) —
вес × повторы и блины на каждую сторону (`platesFor(weight, bar)` из того же файла; `null` — не собрать — показать «нельзя собрать точно»). Рабочий вес ≤ гриф — «Разминка с
пустым грифом». Текст и FAQ: зачем разминаться, сколько подходов, почему повторов меньше ближе к рабочему весу; в
тренировке Hero Fit разминка добавляется одной кнопкой.

Оба: метаданные и `toolJsonLd` как у `/tools/1rm`; числовые поля — с `selectOnFocus`.

## Общее

- `proxy.ts` `PUBLIC_PAGES`: `/training-programs`, `/tools/dots-wilks`, `/tools/warmup`; `PUBLIC_PREFIXES`:
  `/training-programs/`.
- `PUBLIC_SITEMAP` (`lib/seo.ts`): `/training-programs` (0.8, weekly), каждая программа (0.8, monthly), два
  калькулятора (0.8, monthly). `robots.ts` — без изменений (разрешено всё, кроме перечисленного).
- Лендинг: в подвале — «Программы тренировок» и новые калькуляторы; в разделе «Как это работает» или рядом с
  калькуляторами — ссылка на программы. Перекрёстные ссылки между калькуляторами.
- `docs/features/platform.md` (лендинг и SEO) — описать страницы, модуль программ и цель.

## Тесты

- Unit: `strength-score` (опорные значения, ограничения веса, `dotsLevel` на границах 199.99/200/500), данные программ
  (slug уникальны и из `[a-z0-9-]`; у каждого дня ≥ 1 упражнение; все упражнения есть в каталоге сида; FAQ ≥ 4;
  `description` ≤ 160), `sitemapEntries` содержит новые адреса.
- e2e (`e2e/seo-programs.spec.ts`): страницы программ и калькуляторов без входа — `h1`, canonical, JSON-LD
  разбирается; 404 для неизвестной программы; «Начать программу» гостем → регистрация → `/training` с упражнениями
  первого дня; вошедший → `/training` с первым днём; при идущей тренировке — `/training` без новой тренировки;
  расчёт DOTS/Wilks и лесенка разминки; `sitemap.xml` содержит новые адреса (в e2e sitemap отдаётся и при noindex —
  проверить).
