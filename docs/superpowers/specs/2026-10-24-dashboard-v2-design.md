# Дашборд v2: «Сегодня + моя неделя» и инфографика прогресса

## Зачем

Сейчас `/dashboard` — лента из 15+ однотипных карточек: главные цифры (уровень, серия, неделя) разбросаны, инфографики почти нет
(график объёма за 7/30 дней и карта мышц), плитки статистики — голые числа. Цель — за 3 секунды человек понимает, что
делать сегодня и как идёт его неделя; ниже — наглядный прогресс, затем игра и сообщество.

Решения пользователя (визуальный брейншторм 2026-10-24): верх — «полоса недели» (вариант B), инфографика — все шесть
виджетов, компоновка — ярусы во всю ширину (A), стиль — ровные карточки, как сейчас (A), эксперимент — под флагом.

## Включение

- Флаг `dashboard_v2` в `lib/flags/registry.ts` (`expires` — 2027-06-30). `app/(app)/dashboard/page.tsx` при флаге рендерит
  `components/dashboard-v2/dashboard-v2.tsx`, иначе — нынешнюю страницу без изменений (старые e2e не трогаются).
- Ветка `feat/dashboard-v2` от `release/2027-03-next`. Пункт «Что нового» — с `flag: "dashboard_v2"`.
- Без флага новые запросы не выполняются.

## Компоновка

Одна колонка ярусов во всю ширину (`max-w-6xl`), на телефоне — тот же порядок. Заголовки ярусов «Прогресс», «Игра»,
«Сообщество» (`h2`), у яруса «Сегодня» заголовок — приветствие (`h1`).

### Ярус «Сегодня»

1. Приветственный блок (тот же градиент, что сейчас): «Привет, {имя}!», кнопка «Начать / Продолжить тренировку» —
   по-прежнему самая заметная. Подпись — состояние недели:
   - есть активная тренировка → «Тренировка «X» ждёт продолжения» (как сейчас);
   - неделя ещё не засчитана → «Ещё {N} {тренировка/и/ок} — и неделя засчитана в серию» (N = `STREAK_WEEK_TARGET` − тренировок недели);
   - засчитана → «Неделя засчитана — серия {n} {неделя/и/ь}»;
   - `isStreakUrgent` → как сейчас («Тренировка сегодня спасёт серию недели»).
2. **Полоса недели** внутри блока: 7 плиток пн…вс текущей недели в `User.timeZone`. Состояния плитки:
   `done` (была завершённая тренировка — закрашена, ✓), `today` (обводка), `planned` (есть запись плана — точка),
   `rest` (прошедший день без тренировки), `future`. `done` + `today` возможны вместе. Подпись дня — «пн»…«вс»,
   `aria-label` — «Пятница, 24 октября: тренировка» и т.п.; вся полоса — `role="list"` с подписью «Неделя».
3. **Чипы** справа от полосы (на телефоне — строкой под ней): «⚡ Ур. {L} · {p} %» (ссылка на `/achievements`),
   «🔥 {n} нед.» (серия, при нулевой — «Серия не начата»), «❄ {k}» (заморозки, если > 0). Кнопка восстановления серии
   (`RestoreStreakButton`) и текст о сгорании переезжают из нынешней карточки серии под полосу, когда `restoreOffer` есть.
4. Как сейчас, если есть: `TodayPlan`, `MyCoachCard`, `RecapCard`.

### Ярус «Прогресс»

Сетка (≥ lg): ряд 1 — «Неделя в цифрах» (2/4) · «Тренд силы» (1/4) · «Свежие рекорды» (1/4); ряд 2 — «Тренд объёма»
(2/3) · «Баланс нагрузки» (1/3); ряд 3 — «Тепловая карта»; ряд 4 — «Карта мышц» (только восстановление).
На md — по две, на телефоне — по одной.

- **Неделя в цифрах**: объём (`formatTonnage`), время в зале, подходы, рекорды — за текущую неделю (пн…сегодня)
  против того же числа дней прошлой недели; изменение — «▲ 12 %» / «▼ 5 %» / «как неделю назад», у рекордов — без
  сравнения. Нет прошлой недели — только числа. Цвет изменения — `text-primary` (рост) / `text-muted-foreground` (снижение), не красный:
  снижение объёма — не ошибка; стрелка и знак дублируют цвет.
- **Тренд силы**: из `getMonthCompare` (только при `strength_analytics`): `trendHeadline` и топ-3 `trendLine`.
  Нет флага или `of < TREND_MIN_SESSIONS`-данных → виджет не рендерится, «Свежие рекорды» занимают 2/4.
- **Свежие рекорды**: 3 последних `PersonalRecord` (типы MAX_WEIGHT, ONE_RM, MAX_REPS, MAX_DURATION, MAX_DISTANCE)
  за 30 дней с приростом к предыдущему значению того же упражнения и типа; первая запись — «первый результат».
  Строка — ссылка на график упражнения (`/stats/exercises/<id>` — та же ссылка, что в статистике). Нет — «Рекорды
  появятся после тренировок».
- **Тренд объёма**: `getTrends().weekly` (12 недель) через существующий `components/stats/weekly-trend-chart.tsx`.
- **Баланс нагрузки**: кольцевая диаграмма по `getMuscleBalance` (30 дней): топ-5 групп + «прочие», подписи с процентами
  в легенде, итог подходов в центре. Нет данных — заглушка.
- **Тепловая карта**: `getTrends().activity` (26 недель) через `components/stats/activity-heatmap.tsx`.
- **Карта мышц**: `BodyMap` только с восстановлением (новый проп `views={["recovery"]}`; вкладка «Баланс» — на `/stats`
  и в старом дашборде остаётся).

Плитки «Тренировок всего / за 7 / за 30 дней / в зале за 7 дней», карточки «Уровень» и «Серия», график объёма 7/30
и карточка «Последняя тренировка» в v2 не выводятся: их заменяют чипы, «Неделя в цифрах», тренд объёма и рекорды.
Последняя тренировка — строкой-ссылкой «Последняя тренировка: {название} · {дата} →» под полосой недели, если она была
за последние 14 дней.

### Ярусы «Игра» и «Сообщество»

Существующие компоненты без изменений: «Игра» — `BossCard` (2/3) · «Ближайшая ачивка» `GoalCard` (1/3), затем
`GoalsCard`; «Сообщество» — `GuildCard` · `ClubCard` (как сейчас — рядом, если есть клуб), затем «Друзья недавно».
Внизу — строка о часовом поясе. `WhoopRecoveryCard` — в ярусе «Сегодня» после `TodayPlan` (это про сегодняшнюю готовность).

## Данные

Новый модуль `lib/dashboard/v2-queries.ts` (server-only), чистые функции — `lib/dashboard/v2.ts` с unit-тестами.

- `weekStrip(input: { today: string; workoutDays: string[]; plannedDays: string[] }): StripDay[]` — чистая;
  `StripDay = { day: string; weekday: 0..6; done: boolean; today: boolean; planned: boolean; past: boolean }`.
  Дни тренировок — местные дни `finishedAt` завершённых тренировок недели (в `User.timeZone`), план — дни вхождений
  `getCalendar(userId, monday, sunday, tz)`.
- `weekCompare(cur: WeekTotals, prev: WeekTotals): WeekCompareView` — чистая; `WeekTotals = { volume, seconds, sets, records }`;
  изменение в процентах округляется, prev = 0 → без процента. Запрос — одна агрегация по двум окнам
  (`[monday, now)` и `[monday − 7 д, now − 7 д)`), рекорды — `PersonalRecord.achievedAt` в тех же окнах.
- `recentRecords(userId, limit = 3)` — запрос с `LAG()` по (exerciseId, type) для прироста.
- `balanceSlices(rows: { group; sets }[], top = 5)` — чистая свёртка для кольца.
- Остальное — существующие `getTrends`, `getMonthCompare`, `getMuscleBalance`, `getMuscleRecovery`, `getDashboard`
  (стрик, уровень, активная тренировка), `getTodayPlan` и т.д.
- Все запросы v2 — одним `Promise.all` в `page.tsx`. Замер: время рендера `/dashboard` на demo до/после (в описании ветки).

## Доступность и стиль

Ровные карточки `rounded-xl border bg-card p-4`, только семантические токены (`primary`, `xp`, `streak`, `chart-*`,
`series-*`); у каждого графика — скрытая таблица (`sr-only`), как в `components/admin/metrics-charts.tsx`.
Палитра кольца — `--series-1…5` + `muted-foreground` для «прочих» (проверены валидатором в обеих темах; CVD 7.7 —
с легендой-процентами). Анимаций сверх существующих (`XpBar`, `StreakFlame`) нет; «уменьшить движение» учитывается.

## Тесты

- Unit: `weekStrip` (неделя с пн, сегодня в середине/в воскресенье, план и тренировка в один день, пояс — граница суток),
  `weekCompare` (рост/падение/ноль/нет прошлой), `balanceSlices` (меньше 5 групп, «прочие», доли в сумме 100).
- e2e `e2e/dashboard-v2.spec.ts` (флаг `addFlagUser("dashboard_v2")`, desktop и mobile): засеянные тренировки этой недели
  (`seedWorkouts` с днями недели через `localAt`) → плитки дней закрашены, подпись «Ещё N…», «Неделя в цифрах» показывает
  объём; рекорд → строка в «Свежих рекордах»; без флага — старый дашборд (плитка «Тренировок всего» на месте).
  Скриншоты обеих тем перед ревью — глазами.

## Не делаем

Перетаскивание и скрытие виджетов, новый стиль карточек, изменения `/stats`, удаление старого дашборда (после
раскатки флага — отдельной правкой).
