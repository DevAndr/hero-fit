# Режим тренера: копирование плана с клиента на клиента

Первая из трёх следующих фич для тренеров (дальше — задания сразу нескольким, группы клиентов). Копирование частично
закрывает «задания нескольким»: настроил одному — скопировал остальным.

## Цель

Тренер настроил клиенту план — назначения и задания по шаблонам — и хочет такой же у другого клиента или нескольких,
не собирая заново.

## Решения

- **Что копируется** — только назначения этого тренера и задания по их шаблонам:
  - серии, у которых `endDate` пусто или ≥ сегодня: правило целиком (шаблон, день недели, время, длительность,
    `endDate`), `startDate = max(startDate, сегодня)`; исключения серии (переносы, пропуски) не копируются;
  - разовые записи (`seriesId = null`) с `date ≥ сегодня`, не `cancelled`;
  - задания (`CoachTarget`) источника по шаблонам скопированных назначений и упражнениям, которые есть в шаблоне
    сейчас; `fails` = 0, `unloadedAt` = null.
- **«Сегодня»** — в поясе источника. Даты копируются как есть (даты календаря местные у каждого — как в «Назначить
  нескольким»).
- **Веса:** галочка «С весами», по умолчанию выключена. Без неё у заданий вес и шаг пустые (шаг без веса не работает);
  задание, у которого после этого всё пусто, не копируется.
- **У получателя уже есть план** — добавляем рядом, ничего не удаляем. Задания по тем же шаблон + упражнение
  перезаписываются копией (подходы, повторы, вес, шаг; без «С весами» вес и шаг тоже становятся пустыми), остальные
  задания получателя не трогаются. В диалоге у получателя подпись «перезапишется N заданий».
- **Получатели** — активные клиенты тренера, без источника, не больше 50; остальные id пропускаются (`pickClients`).
- **Уведомление** — каждому получателю одно `COACH` «Новый план от тренера», текст — сводка.

## Интерфейс

Вкладка «План» карточки клиента: кнопка «Скопировать план» рядом с «Назначить» — видна, если у клиента есть что
копировать (сводка не пустая) и у тренера есть другие клиенты. Диалог «Скопировать план»:

- сводка «Будет скопировано: 2 серии, 1 разовая тренировка, 5 заданий»;
- группа «Клиенты» (`role="group"`) с «Выбрать всех» — общий `ClientPicker` (выносится из `assign-dialog.tsx`, строка
  может нести подпись); у получателя с перезаписью — «перезапишется 3 задания»;
- чекбокс «С весами»;
- «Скопировать» неактивна без отмеченных; после — тост «План скопирован 2 клиентам» (`· 1 пропущен`), закрытие.

## Модули

- `lib/coach/plan-copy.ts` (чистые):
  - `copyPlan(source, today, { withWeights })` → `{ series, entries, targets }` для создания у получателя;
  - `copySummary({ series, entries, targets })` → «2 серии, 1 разовая тренировка, 5 заданий» (`plural`; пустые части
    не пишутся; всё пусто — `null`);
  - `overwriteCount(copied, recipient)` — число заданий получателя с тем же шаблон + упражнение;
  - `copyPlanText(n, skipped)` — «План скопирован 2 клиентам · 1 пропущен».
- `lib/coach/plan-copy-queries.ts` — `getPlanCopySource(coachId, clientId, today)` и ключи заданий остальных клиентов
  тренера (`templateId:exerciseId`) для подписи.
- `lib/coach/plan-actions.ts` — `copyPlanAction(sourceId, clientIds, { withWeights })`: `requireClientOf(sourceId)`,
  `pickClients` (источник исключён), одна транзакция (запросы по очереди, `timeout: 30_000`), серии и записи —
  `createMany` с `coachId`, задания — upsert, уведомление; цель Метрики `coach_copy_plan`; `revalidatePath` карточек и
  `/coach`; ответ `{ ok: true, copied, skipped }`; нечего копировать — `{ ok: false, error: "Нечего копировать" }`.
- `components/coach/client-picker.tsx` — общий `ClientPicker` (используют `AssignDialog` и `CopyPlanDialog`).
- `components/coach/copy-plan-dialog.tsx` — `CopyPlanButton` + диалог.

## Тесты

- Unit `lib/coach/plan-copy.test.ts`: закончившаяся серия не копируется; начало серии сдвигается на сегодня, будущее
  начало — без изменений; прошедшая и отменённая разовые и исключения серии не копируются; без весов — вес и шаг
  пустые, задание только с весом пропускается; с весами — как есть, `fails` не переносится; `copySummary`,
  `overwriteCount`, `copyPlanText`.
- e2e `e2e/coach-copy-plan.spec.ts`: у Маши серия и задание 4 × 8 · 60 кг с шагом → «Скопировать план» Боре без весов →
  у Бори в календаре «от тренера», уведомление «Новый план от тренера», задание 4 × 8 без веса; с весами — 60 кг и шаг;
  старое задание Бори по тому же упражнению перезаписано, по другому — осталось; подпись «перезапишется 1 задание».

## Вне фичи

Замена плана получателя, копирование исключений серии, копирование своих (не тренерских) планов, обратная связь
«скопировано с …».
