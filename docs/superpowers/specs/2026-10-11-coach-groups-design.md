# Режим тренера: группы клиентов

Третья из следующих фич для тренеров (копирование плана — сделано; задания сразу нескольким — отложены, их частично
закрывает копирование).

## Цель

Тренер с десятками клиентов раскладывает их по группам («Утро пн/ср/пт», «Онлайн») — чтобы смотреть список по группе и
одним нажатием отмечать группу в «Назначить нескольким» и «Скопировать план». Назначения у каждого клиента остаются
свои: у группы нет своего плана.

## Решения

- **Группы — метки:** клиент может быть в нескольких группах. Клиент о группах не знает и не получает уведомлений.
- **Управление** — диалог «Группы» на `/coach` (рядом с «Назначить нескольким»): список групп с числом участников;
  «Создать группу» — название + галочки клиентов (`ClientPicker`); у группы «Изменить» (название и состав) и «Удалить»
  (подтверждение «Клиенты останутся, удалится только группа»). Название 1…40 символов, уникально у тренера без учёта
  регистра; групп — до 20.
- **Список `/coach`:** строка фильтров «Все · Утро пн/ср/пт (5) · Онлайн (3)», выбор — `?group=<id>` (нет такой группы —
  все); у клиента в строке — значки его групп; порядок — прежний (`sortClients`).
- **Быстрый выбор:** в «Назначить нескольким» и «Скопировать план» над списком клиентов — кнопки групп; нажатие
  добавляет к выбору участников группы, которые есть в списке (источник копирования — нет). Групп нет — кнопок нет.
- **Карточка клиента:** значки его групп под именем, только чтение.
- **Разрыв связи** — клиент убирается из всех групп этого тренера (`dropAssignments`).

## Данные

Миграция `coach_groups`:

- `CoachGroup`: `id`, `coachId` → `User` (cascade), `name`, `nameKey`, `createdAt`; `@@unique([coachId, nameKey])`.
- `CoachGroupMember`: `groupId` → `CoachGroup` (cascade), `clientId` → `User` (cascade), `createdAt`;
  `@@id([groupId, clientId])`, `@@index([clientId])`.

## Модули

- `lib/coach/groups.ts` (чистые): `COACH_GROUPS_MAX = 20`; `groupSchema` (name: trim, 1…40 — «Введите название» / «Не
  больше 40 символов»); `groupKey(name)` — trim, пробелы схлопнуты, нижний регистр; `inGroup(rows, group)` —
  строки списка, чьи id в `group.clientIds` (группы нет — все); `addGroup(picked, members, available)` — `picked` +
  участники из `available` без повторов, порядок — как в `available`.
- `lib/coach/group-queries.ts` — `getCoachGroups(coachId): { id; name; clientIds }[]` по `name`, участники — только
  активные клиенты тренера.
- `lib/coach/group-actions.ts` — `saveGroupAction(id: string | null, input: { name; clientIds })` (`requireCoach`;
  клиенты — `pickClients` по активным, остальные молча отбрасываются; ≤ 20 групп — «Не больше 20 групп»; занятый
  `nameKey` — «Такая группа уже есть»; чужая/нет — «Группа не найдена»; состав заменяется целиком в транзакции) и
  `deleteGroupAction(id)`; `revalidatePath("/coach")`.
- `dropAssignments` — `coachGroupMember.deleteMany` по группам тренера и клиенту.
- UI: `components/coach/groups-dialog.tsx` (`GroupsButton`), фильтр `components/coach/group-filter.tsx` (ссылки),
  значки — в `ClientList` и в шапке карточки; кнопки групп — в `ClientPicker` (необязательный проп `groups`).

## Тесты

- Unit `lib/coach/groups.test.ts`: `groupSchema` (пустое, 41 символ, обрезка), `groupKey` («  Утро  ПН » → «утро пн»),
  `inGroup`, `addGroup` (повторы, участник вне списка, порядок).
- e2e `e2e/coach-groups.spec.ts`: тренер с тремя клиентами создаёт группу из двоих → фильтр на `/coach` показывает
  двоих, значок у клиента → «Назначить нескольким» → кнопка группы отмечает обоих; повтор названия — ошибка;
  переименование; удаление; клиент разорвал связь — в группе его больше нет.

## Вне фичи

План группы (назначение группе с автодобавлением новичков), страница группы, группы в «Задания по шаблонам», цвета
групп.
