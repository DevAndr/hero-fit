# Своя прогрессия в шаблоне

Первая из идей для основного приложения (2026-10-11). Переносит прогрессию тренера
(`docs/superpowers/specs/2026-10-10-coach-progression-design.md`) на свои шаблоны пользователя.

## Цель

Пользователь без тренера задаёт в своём шаблоне цель упражнения (подходы × повторы × вес) и шаг — и вес растёт сам:
выполнил цель — +шаг, не выполнил — повтор, третья неудача подряд — разгрузка.

## Решения

- **Где включается** — в редакторе своего шаблона: у упражнения поле «Шаг, кг» (0,5…20, пусто — выключено). Прогрессия
  работает при заданных весе (`targetWeight`) и шаге. Шаг без веса — «Для прогрессии нужен вес». Подпись под строкой —
  «Прогрессия: +2,5 кг, когда сделаешь 4 × 8 · 60 кг» (без повторов в шаблоне — по 1 повтору).
- **Правило** — то же `progressTarget` (`lib/coach/progression.ts`): не меньше N подходов (`targetSets`) с весом ≥ цели и
  повторами ≥ R (`targetReps`, пусто — 1) → вес + шаг, `fails` = 0; иначе неудача; на 3-й подряд — разгрузка
  `floor(вес × 0,9 / 2,5) × 2,5`, `fails` = 0; без выполненных рабочих подходов — не попытка.
- **Запуск** по своему шаблону (`fromTemplate`, источники `template:`/`plan:`) и повтор (`repeat:`) тренировки по нему:
  строки с весом и шагом — цель для `plannedSets` (вес — из шаблона, а не из истории); строки без шага — как раньше.
- **Завершение** — `applyOwnProgression` в транзакции `finishWorkout`, только если шаблон тренировки — свой
  (`userId` = пользователь); обновляет у строки `targetWeight` и `fails`. Тренерская `applyProgression` не меняется
  (только шаблоны активного тренера) — пересечения нет.
- **Сводка** — блок «Прогрессия» (у своего шаблона) вместо «План тренера», те же строки `progressionLine`.
  `FinishMeta.progression` получает признак источника.
- **Редактор пересоздаёт строки** — `fails` переносятся по упражнению: вес и шаг не менялись — счётчик остаётся, иначе 0
  (чистая `carryFails`). «Копировать в мои шаблоны» копирует шаг, `fails` = 0.
- **«Пора увеличить вес»** — в редакторе тренировки не показывается у упражнения, у которого в шаблоне тренировки
  включена прогрессия.
- **Не работает:** готовые программы (сначала копия), шаблоны тренера (там задания тренера). Упражнение своим весом —
  вес как отягощение («+10 кг»), как у тренера.

## Данные

Миграция `template_progression`: `TemplateExercise.step Float?`, `TemplateExercise.fails Int @default(0)`.

## Модули

- `lib/templates/schema.ts` — `step` (0,5…20 или null) + проверка «Для прогрессии нужен вес».
- `lib/templates/progression.ts` (чистые): `carryFails(old: { weight; step; fails } | undefined, next: { weight; step })`;
  `ownTarget(te)` → `Target` для `plannedSets` или null (нет веса или шага); `progressionHint(te)` — подпись редактора.
- `lib/progress/own-progression.ts` — `applyOwnProgression(tx, userId, workout)` → `ProgressionItem[]`.
- `lib/workouts/finish.ts` — вызывает обе прогрессии; `FinishMeta.progression` + `progressionSource: "own" | "coach"`.
- `lib/workouts/actions.ts` — цели своего шаблона в `fromTemplate` и в повторе.
- Сводка — заголовок по источнику; редактор тренировки — без подсказки у упражнений с прогрессией.

## Тесты

- Unit: `carryFails` (без изменений — тот же; вес/шаг сменились — 0; новой строки — 0), схема (шаг без веса, границы),
  `ownTarget`, `progressionHint`.
- e2e `e2e/own-progression.spec.ts`: шаблон «Присед 4 × 8 · 60, шаг 2,5» → тренировка из шаблона, 4 × 8 с 60 →
  сводка «Прогрессия» «в следующий раз 62,5 кг (+2,5)» → новый запуск подставляет 62,5; неудача — «повторим …
  неудача 1 из 3»; смена шага в редакторе обнуляет неудачи; у упражнения с прогрессией нет «Пора увеличить вес».

## Вне фичи

Прогрессия по повторам (двойная прогрессия), разные шаги для разных упражнений по умолчанию, прогрессия в готовых
программах без копии, история изменений цели.
