# Гильдии (рейды, цикл 1 из 3)

Релиз `release/2026-10-raids`. Механика рейдов согласована 2026-10-11: (1) гильдии — этот документ, (2) рейд-босс
гильдии, (3) ачивки, титулы, лендинг. Цикл 1 без рейда на прод не выходит — релиз собирается целиком.

## Цель

Игроки объединяются в гильдию до 10 человек: видят тренировки и недельные цифры друг друга, зовут знакомых ссылкой.
Основа для общего рейд-босса (цикл 2).

## Решения

- **Видимость** — как у друзей: вступление = согласие показывать гильдии ник, тренировки (лента гильдии), опыт за
  неделю. `shareActivity` («Показывать мои тренировки друзьям и гильдии») и `hideWeights` действуют так же.
- **Вступление** по ссылке `/guild/join/<код>` или коду — сразу, без заявки; глава исключает и меняет ссылку.
- **Одна гильдия на игрока**, до 10 участников (`GUILD_MAX`), нужен ник (как для лиги).
- **Глава:** переименовать и сменить значок, исключить, передать главенство, сменить ссылку (старая — 404). Глава не
  выходит, пока в гильдии есть другие; последний вышедший удаляет гильдию.
- **Название** 3–24 символа, уникально без учёта регистра (`nameKey`); **значок** — из набора `GUILD_EMBLEMS`
  (~12 иконок lucide: щит, меч, молот, корона, пламя, волк…).

## Интерфейс

- `/guild` без гильдии: «Создать гильдию» (название + значок) и «Вступить по коду»; без ника — сначала форма ника
  (`NicknameForm`).
- `/guild` с гильдией: шапка (значок, название, «7/10 участников»); **Состав** — ник, титул, тренировок и опыт за эту
  неделю (как очки лиги: `WORKOUT_COMPLETED` + `PERSONAL_RECORD`, неделя — по поясу смотрящего), метка «глава»,
  сортировка по опыту; **Лента гильдии** — завершённые тренировки участников с 👊 (подгрузка курсором, как `/friends`);
  **Пригласить** — ссылка, код, «Копировать», у главы «Сменить ссылку»; у главы в строке участника — «Исключить»,
  «Сделать главой»; «Настройки гильдии» (название, значок); «Выйти из гильдии» (подтверждение; главе при других
  участниках — «Сначала передайте главенство»).
- `/guild/join/<код>`: «Вступить в гильдию «…»?», значок, состав, «Вступить»; уже в другой — «Вы выйдете из «…»»;
  уже в этой — переход на `/guild`; мест нет — «В гильдии нет мест»; неверный код — 404. Гость — вход/регистрация с
  `next` (как `/coach/join`).
- Меню: «Гильдия» в боковом (ПК) и в меню профиля (телефон, как «Клиенты»). Дашборд — карточка «Гильдия»: без
  гильдии — «Создайте гильдию или вступите по ссылке», с гильдией — название и «потренировались N из M на этой неделе».
- Уведомления (`SOCIAL`): главе — «<ник> вступил(а) в гильдию» → `/guild`; исключённому — «Вас исключили из гильдии
  «…»»; новому главе — «Вы теперь глава гильдии «…»». 👊 от согильдийца, который не друг, ведёт на `/guild#w-<id>`.

## Данные

Миграция `guilds`:

- `Guild`: `id`, `name`, `nameKey @unique`, `emblem`, `code @unique` (8 символов, алфавит кода друга),
  `leaderId` → `User`, `createdAt`.
- `GuildMember`: `userId @id` → `User` (cascade), `guildId` → `Guild` (cascade), `joinedAt`; `@@index([guildId])`.

Удаление аккаунта главы (только вручную по письму) — `leaderId` restrict; при ручном удалении — сначала передать.

## Модули

- `lib/guild/rules.ts` (чистые): `GUILD_MAX = 10`, `GUILD_EMBLEMS`, `guildNameSchema`, `guildKey`, `leaveBlock(isLeader,
  members)` → null | «Сначала передайте главенство», `joinBlock({ members, inThis, other })` → null | код отказа.
- `lib/guild/actions.ts`: `createGuildAction`, `joinGuildAction(code)` (транзакция: `SELECT … FOR UPDATE` строки гильдии,
  проверка мест, выход из прежней, вставка, уведомление главе), `leaveGuildAction`, `kickMemberAction`,
  `transferLeadAction`, `updateGuildAction`, `regenerateGuildCodeAction`; P2002 по названию — «Такая гильдия уже есть».
- `lib/guild/queries.ts`: `getMyGuild(userId, tz)`, `getGuildByCode(code)`, `guildMateIds(userId)`.
- `lib/social/queries.ts`: общий `feedPage(viewerId, authorIds, cursor)`; `getFeed` (друзья) и `getGuildFeed` (гильдия)
  поверх него; `canSeeWorkout` — друзья или согильдийцы; ссылка уведомления 👊 — по отношению.
- Страницы `app/(app)/guild/page.tsx`, `app/(app)/guild/join/[code]/page.tsx`; компоненты `components/guild/*`.

## Тесты

- Unit `lib/guild/rules.test.ts`: название (2/25 символов, обрезка), `guildKey`, `leaveBlock`, `joinBlock`.
- e2e `e2e/guilds.spec.ts`: без ника — форма ника; создать → второй по ссылке видит экран и вступает → у главы
  уведомление, в составе двое; тренировка второго в ленте гильдии, с «Скрыть веса» — без килограммов; 👊; заполненная
  (10) — «В гильдии нет мест»; исключить; передать главенство; сменить ссылку — старая 404; выход последнего удаляет
  гильдию; глава с участниками не выходит.
