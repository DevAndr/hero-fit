# Кардио и упражнения на время

Релиз `release/2026-11-formats`, подпроект 2 из 2 (первый — суперсеты), под фича-флагом `workout_formats` —
экспериментально.

## Цель

Кроме силовых (вес × повторы) — упражнения **на время** (планка, вис, стульчик: подход = секунды) и **кардио** (бег,
велотренажёр, гребля: подход = время и дистанция). В игре они — полноценные подходы: XP, урон боссу и рейду, гоблин,
задания клуба, рекорды и своя категория ачивок «Выносливость».

Успех: кардио-тренировка даёт XP и урон, а не «пустую» тренировку; у планки и бега свои рекорды; силовая логика
(объём, 1RM, «Пора увеличить вес», «точно столько?», силовые цели, прогрессия) их не задевает.

Вне рамок: упражнения «вес + время/дистанция» (прогулка фермера), секундомер в подходе, импорт из трекеров,
пульс/калории, цели по кардио, кардио в тренде силы.

## Решения

### Данные (миграция `cardio_timed`)

```prisma
enum ExerciseKind { REPS TIME CARDIO }
model Exercise   { … kind ExerciseKind @default(REPS) }
model WorkoutSet { … durationSec Int?  distanceM Int? }   // время подхода, с; дистанция, м
enum RecordType  { … MAX_DURATION MAX_DISTANCE BEST_PACE }
enum AchievementCategory { … ENDURANCE }
```

Сид — встроенные (`userId = null`), идемпотентно:
- `TIME`: «Планка» (ABS), «Боковая планка» (ABS), «Вис на перекладине» (FOREARMS, BACK), «Стульчик у стены» (LEGS);
- `CARDIO`: «Бег», «Ходьба», «Велотренажёр», «Эллипс» (LEGS), «Гребной тренажёр» (BACK, LEGS), «Скакалка» (CALVES).
`defaultRestSec`: 60 у `TIME`, 120 у `CARDIO`. `isBodyweight` — `true`.

### Правила — чистые функции `lib/workouts/kinds.ts`

- `isDoneSet(kind, set: { reps; durationSec?; completedAt })` — выполнен и с результатом: `REPS` — `reps > 0`;
  `TIME`/`CARDIO` — `durationSec > 0`. Заменяет проверки `reps > 0` везде, где решается «подход состоялся»
  (итоги, удаление пустых при завершении, XP, босс, рейд, гоблин, задания клуба, рекорды, ачивки).
- `workoutTotals` — `sets` считает все выполненные рабочие подходы; `reps` и `volume` — только `REPS`; новое
  `workSec` — Σ `durationSec` подходов `TIME`/`CARDIO`; `distanceM` — Σ дистанций `CARDIO`.
- `formatDuration`-подобные: `formatClock(sec)` → «1:30», «1:02:05»; `parseClock("1:30") → 90`, `"90" → 90`,
  `"1:02:05" → 3725`, мусор → 0; `formatPace(sec, m)` → «5:31/км» (только при `m ≥ 1000`); `formatKm(m)` → «5,2 км».

### XP

`workoutXp({ sets, reps, volume, workSec })` = 50 + 5·подходы + ⌊повторы/5⌋ + ⌊объём/200⌋ + **⌊workSec/60⌋**,
потолок 600 и бонус 25 за побитый рекорд — как сейчас. `Workout.totalReps`/`totalVolume` — только силовые.

### Рекорды (`lib/progress/records.ts`)

- `TIME`: `MAX_DURATION` — самый долгий подход.
- `CARDIO`: `MAX_DISTANCE` — самый длинный подход; `MAX_DURATION`; `BEST_PACE` — сек/км, **меньше — лучше**,
  только подходы с дистанцией ≥ 1000 м.
- Силовые типы (`ONE_RM`, `MAX_WEIGHT`, `MAX_REPS`) у `TIME`/`CARDIO` не считаются. Первый результат — рекорд без
  бонуса (как сейчас). Подписи: «Дольше всего», «Дальше всего», «Лучший темп».

### Ввод в редакторе тренировки

- `SetState` + `duration: string`, `distance: string`; черновик + `durationSec`, `distanceM` (`.nullable().default(null)
  .catch(null)`, старые черновики читаются).
- `TIME` — поле «Время» (`мм:сс`, `inputMode="numeric"`, `selectOnFocus`); `CARDIO` — «Дистанция, км» (`decimal`) и
  «Время». Вес и запас повторов не показываются.
- «Как в прошлый раз» и перенос значений в следующий пустой подход — и для времени/дистанции.
- Не применяются: «точно столько?», подсказка «Пора увеличить вес», помощник «совет по весу», разминка (кнопка
  разминки скрыта у `TIME`/`CARDIO`).

### Упражнения

- Форма своего упражнения: выбор «Повторы / Время / Кардио» (только при флаге; без — `REPS`). Вид встроенного не
  меняется; у своего — менять можно, пока нет выполненных подходов.
- Без флага упражнения `TIME`/`CARDIO` скрыты в каталоге, выборе для тренировки и шаблона. Уже записанные подходы
  таких упражнений в истории и итогах показываются всегда.
- Страница упражнения — рекорды по виду; график прогресса: `TIME` — лучшее время за тренировку, `CARDIO` — дистанция.

### Шаблоны и тренер

У `TIME`/`CARDIO` в шаблоне — только число подходов и отдых (поля повторов/веса/шага скрыты). Прогрессия тренера и своя
прогрессия такие строки пропускают. Силовые цели — только упражнения `REPS`.

### Игра

Подход `TIME`/`CARDIO` — обычный подход для: урона боссу и рейду (RIR нет → урон по `setDamage(null)`), гоблина
(броски и поимка), заданий клуба «на подходы», ачивок по подходам. Задания клуба «на объём/повторы» их не считают.

### Ачивки — категория ENDURANCE («Выносливость»)

Новые поля `AchievementStats`: `cardioDistanceM` (Σ), `workSec` (Σ `TIME`+`CARDIO`), `longestCardioSetM`,
`longestTimeSetSec`, `hybridWorkouts` (тренировки с ≥ 1 выполненным `REPS` и ≥ 1 `CARDIO`).

| Код | Ступени | Название | XP |
|---|---|---|---|
| `cardio_km:N` | 10, 42, 100, 250, 500, 1000 (дальше шаг 500) | 10 — «Первая десятка», 42 — «Марафонская дистанция», иначе «Дорога: N км» | `Math.round(20 + n / 5)` |
| `work_hours:N` | 1, 5, 10, 25, 50 (шаг 50) | «Кардио: N ч» | `Math.round(20 + n)` |
| `cardio_set:M` (метры) | 5000, 10000, 21100, 42200 | «Пятёрка», «Десятка», «Полумарафон», «Марафон» | 30, 40, 60, 100 |
| `hold:S` (секунды) | 60, 120, 180, 300 | «Стойкость: N мин» | 20, 30, 40, 60 |
| `hybrid:N` | 1, 10, 50 | 1 — «Гибрид», иначе «Гибрид ×N» | `25 + n` |

Без флага категория «Выносливость» на странице ачивок скрыта (уже полученные показываются). Входят в «Коллекционера»
и дают монеты, как остальные.

### Показ

- Итоги/история/лента/у тренера: «Планка 1:30, 1:15»; «Бег 5,2 км · 28:40 · 5:31/км» (без дистанции — только время).
- Итоги тренировки — плитка «Кардио» (минуты, км), если есть такие подходы.
- Статистика — блок «Кардио»: минуты и км за неделю и месяц (при флаге).
- «Мои данные»: `durationSec`, `distanceM` у подходов, `kind` у своих упражнений; CSV — колонки `duration_sec`,
  `distance_m`.

### «Что нового»

Пункт в записи релиза: «Кардио и упражнения на время: бег, велотренажёр, планка — с рекордами, XP и ачивками
„Выносливость“», `flag: "workout_formats"`.

## Тестирование

Unit: `kinds.test.ts` — `isDoneSet` по видам, `parseClock`/`formatClock`/`formatPace`/`formatKm`, `workoutTotals`
(смешанная тренировка: повторы и объём только силовые, `workSec`, `distanceM`); `xp.test.ts` — минуты в XP и
потолок; рекорды — `MAX_DURATION`, `MAX_DISTANCE`, `BEST_PACE` (меньше лучше, < 1 км не считается), силовые типы
у кардио не появляются; ачивки — ступени пяти лестниц и названия; схема черновика без новых полей.

e2e (`e2e/cardio.spec.ts`, флаг на пользователя, desktop и mobile): тренировка «Бег» 5,2 км 28:40 + «Планка» 1:30 →
итоги: «5,2 км · 28:40 · 5:31/км», «1:30», XP > 50, рекорды «Дальше всего»/«Дольше всего», ачивка «Пятёрка»; без
флага «Планки» нет в каталоге; своё упражнение «Кардио» создаётся и попадает в тренировку.

## Review Focus

- Подход кардио с 0 повторов не удаляется при завершении и не выпадает из итогов, XP, урона, гоблина.
- Силовые места (объём, 1RM, тренд силы, «точно столько?», прогрессия, цели) не получают кардио-данных.
- `BEST_PACE`: меньше — лучше; подход без дистанции или < 1 км рекорд не ставит и не сбрасывает.
- Старый черновик на устройстве без `durationSec`/`distanceM` читается.
- Без флага: каталог без новых видов, но история с ними не ломается.
