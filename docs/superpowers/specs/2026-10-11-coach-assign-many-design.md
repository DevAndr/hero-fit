# Режим тренера: назначение шаблона нескольким клиентам

Третья из трёх фич для тренеров (1 — сигналы риска, 2 — оценка тренировки; обе в `main`).

## Цель

Тренер с группой клиентов назначает одну тренировку или серию сразу нескольким — одним диалогом, а не по очереди
из карточки каждого. Сейчас назначение — только из вкладки «План» одного клиента (`assign-dialog.tsx` →
`assignWorkoutAction`).

## Решения

- **Вход:** список клиентов `/coach` — кнопка «Назначить нескольким» (видна при 2+ клиентах). Из `/templates`
  — не сейчас. Именованных групп нет: клиенты отмечаются галочками каждый раз.
- **Модель:** назначение нескольким = обычное назначение, повторённое для каждого отмеченного клиента. У каждого —
  своя независимая разовая запись или серии (`PlanEntry`/`PlanSeries` с `coachId`), правятся и удаляются у
  конкретного клиента. Групповой связи нет — календарь, статусы, задания, прогрессия, сигналы не меняются.
- **Время:** дата и время — местные для каждого клиента, как во всём календаре.
- **Уведомление:** каждому клиенту — «Новый план от тренера», как сейчас.
- **Безопасность:** назначаются только клиенты с активной связью (`CoachLink`, `endedAt = null`) с этим тренером;
  чужие и разорванные id молча пропускаются и считаются в `skipped`. Не больше 50 клиентов за раз.

## Модули

- `lib/coach/assign.ts` — чистая `pickClients(requested: string[], active: string[]): { ids: string[]; skipped:
  number }` (уникальные, в порядке запроса, только из активных; `skipped` — уникальные неактивные) и константа
  `ASSIGN_MANY_MAX = 50`; `assignManyText(n, skipped)` — «Назначено 3 клиентам» / «… · 1 пропущен» (число — с
  `plural`: «клиенту/клиентам», «пропущен/пропущено»).
- `lib/coach/plan-actions.ts`:
  - `assignToClient(tx, coachId, clientId, plan)` — общая часть: запись или серии + уведомление клиенту (выносится
    из `assignWorkoutAction`, тот вызывает её — поведение одиночного не меняется);
  - `assignManyAction(clientIds: string[], input: AssignInput)` — `requireCoach`; ввод — `assignInputSchema`;
    `clientIds` — массив строк, 1…50 (иначе ошибка «Выберите клиентов» / «Не больше 50 клиентов за раз»);
    шаблон — свой; активные связи тренера → `pickClients`; ни одного — `{ ok: false, error: "Клиенты не найдены" }`;
    одна транзакция на всех; цель `coach_assign` один раз; `revalidatePath` `/coach` и карточек; ответ
    `{ ok: true, assigned, skipped }`.
- `components/coach/assign-dialog.tsx` — режим `{ mode: "many"; date }` с пропом `clients: { id; name }[]`:
  сверху группа «Клиенты» (`role="group"`, `aria-label="Клиенты"`) — чекбокс «Выбрать всех» и чекбокс на клиента
  (подпись — имя); заголовок «Назначить нескольким»; «Назначить» неактивна без отмеченных; после успеха — тост
  `assignManyText` и закрытие. Остальные поля — как в режиме создания.
- `/coach` (`app/(app)/coach/page.tsx`) — клиентский `AssignManyButton` (`components/coach/assign-many.tsx`) над
  списком: шаблоны тренера (как во вкладке «План»), клиенты из `getCoachClients` (`id`, `name`), дата по умолчанию —
  сегодня в поясе тренера.

## Тесты

- Unit (`lib/coach/assign.test.ts`): `pickClients` — дубли, чужие id, порядок, `skipped`; `assignManyText` —
  1/2/5 клиентов, с пропуском и без.
- e2e (`e2e/coach-assign-many.spec.ts`): тренер с тремя клиентами отмечает двоих → шаблон, следующий понедельник,
  повтор пн/ср → тост «Назначено 2 клиентам» → у обоих в календаре «от тренера», у обоих уведомление «Новый план от
  тренера», у третьего ничего; правка назначения у первого (вкладка «План» → время) не меняет второго; без отмеченных
  «Назначить» неактивна; «Выбрать всех» отмечает всех.

## Вне фичи

Именованные группы, вход из `/templates`, групповая правка/удаление, задания (`CoachTarget`) сразу нескольким.
