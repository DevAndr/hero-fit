# Программы тренера на несколько недель (мезоциклы)

Дата: 2026-10-16. Релиз: `release/2026-11-next`. Флаг: `coach_programs` — убран до выпуска (2026-10-16), фича доступна всем тренерам.

## Зачем

Сейчас тренер назначает клиенту шаблоны по одному, а вес растёт только автопрогрессией по факту. Онлайн-тренер работает циклами: 4–12 недель с плановым ростом веса и разгрузочными неделями. Программа позволяет задать такой цикл один раз и назначить его клиенту в пару кликов.

## Решения (согласовано)

- Программа = **неделя-шаблон** (день недели → шаблон тренера) + **правило** по неделям. Таблицы «неделя × упражнение» с ручной правкой нет (возможный этап 2 — таблица исключений недели).
- **План по неделям**: вес недели считается по правилу от базового; внутри программы автопрогрессия заданий не действует.
- Правило меняет **только вес** (и подходы в разгрузку). Подходы и повторы — как сейчас (задание → шаблон).
- **Только тренеру**; модель не мешает дать программы самостоятельным пользователям отдельным циклом.
- Вес недели **считается на лету** из снимка правила и баз (вариант A), без фоновых задач.
- У клиента **одна активная программа**; назначение **одному клиенту** (нескольким — не в этом цикле).
- После программы вес последней обычной недели переходит в задание тренера.

## Модель данных

```prisma
enum ProgramStep { PERCENT KG }

/// Программа тренера (библиотека). Изменения действуют только на новые назначения.
model CoachProgram {
  id          String      @id @default(cuid())
  coachId     String
  name        String              // 1…60
  weeks       Int                 // 2…16
  stepKind    ProgramStep
  stepValue   Float               // PERCENT: 0,5…10; KG: 0,5…20
  deloadEvery Int?                // 3…8; null — без разгрузки
  deloadPct   Float  @default(10) // 5…30
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  coach User @relation(onDelete: Cascade)
  days  CoachProgramDay[]
  @@index([coachId])
}

model CoachProgramDay {
  id          String @id @default(cuid())
  programId   String
  weekday     Int    // как PlanSeries.weekday
  templateId  String // свой шаблон тренера
  time        String
  durationMin Int @default(60)
  program  CoachProgram    @relation(onDelete: Cascade)
  template WorkoutTemplate @relation(onDelete: Cascade)
  @@unique([programId, weekday])
}

/// Программа, назначенная клиенту: снимок названия и правила.
model ProgramAssignment {
  id          String  @id @default(cuid())
  clientId    String
  coachId     String?           // null — аккаунт тренера удалён
  programId   String?           // null — программа удалена из библиотеки
  name        String
  startDate   String            // понедельник, "YYYY-MM-DD"
  weeks       Int
  stepKind    ProgramStep
  stepValue   Float
  deloadEvery Int?
  deloadPct   Float
  endedAt     DateTime?         // досрочно / новая программа / разрыв связи
  remindedAt  DateTime?         // «заканчивается через неделю» отправлено
  createdAt   DateTime @default(now())
  client  User  @relation(onDelete: Cascade)
  coach   User? @relation(onDelete: SetNull)
  program CoachProgram? @relation(onDelete: SetNull)
  bases   ProgramBase[]
  series  PlanSeries[]
  @@index([clientId, endedAt])
  @@index([coachId, endedAt])
}

/// Базовый вес упражнения шаблона на момент назначения (тренер правит в диалоге и в «Изменить базу»).
model ProgramBase {
  assignmentId String
  templateId   String
  exerciseId   String
  weight       Float   // 0 — своим весом без отягощения
  /// «Изменить базу» посреди программы: база действует с этой недели (номер недели; 1 — с начала)
  fromWeek     Int @default(1)
  assignment ProgramAssignment @relation(onDelete: Cascade)
  @@id([assignmentId, templateId, exerciseId])
}

// PlanSeries: + programAssignmentId String? (onDelete: SetNull)
```

Активное назначение: `endedAt = null` и сегодня ≤ последний день (`startDate + weeks·7 − 1`) в поясе клиента. Одно активное на клиента — проверяется в транзакции назначения (новое закрывает прежнее).

«Изменить базу» с недели W: база пересчитывается так, чтобы вес недели W был равен введённому, — проще хранить новую базу и `fromWeek = W`, а счёт обычных недель вести от W (неделя W — k = 0). До W веса не пересчитываются (прошлое).

## Правило — чистые функции `lib/coach/program.ts`

- `programWeekIndex(startDate, date)` → номер недели (1…), `null` до старта; после конца — больше `weeks` (вызывающий проверяет).
- `isDeloadWeek(week, deloadEvery)` — `deloadEvery !== null && week % deloadEvery === 0`.
- `loadedWeeksBefore(week, fromWeek, deloadEvery)` — k: число обычных недель в `[fromWeek, week)`.
- `programWeek(rule, base, week)` → `{ weight, setsDelta, deload }`:
  - обычная неделя: `PERCENT` — `base·(1+p)^k`, `KG` — `base + k·step`; округление до 2,5 кг (база < 20 кг — до 0,5 кг); не ниже базы;
  - разгрузка: вес прошлой обычной недели (тот же расчёт с k) × (1 − deloadPct), `setsDelta = −1` (итог подходов ≥ 1);
  - база 0 (своим весом): вес 0, разгрузка — только `setsDelta`.
- `programPreview(rule, base)` — веса всех недель (предпросмотр в редакторе и диалоге, «финальная неделя»).
- `programLabel(week, weeks, deload)` — «Неделя 3/8», «Разгрузка · неделя 4/8».
- Схемы Zod: `programSchema` (поля и диапазоны выше, 1…7 дней, дни без повторов), `assignProgramSchema` (программа, понедельник старта не раньше текущей недели, базы 0…1000).

Пример (проверочный в тестах): база 100, +2,5 %, разгрузка каждая 4-я −10 %: 100 → 102,5 → 105 → **95** (разгрузка, −1 подход) → 107,5 → 110 → 112,5.

## Интерфейс

**Библиотека** — `/coach/programs` (ссылка «Программы» на `/coach`): список, «Новая программа», редактор (название, недели, дни → шаблон и время, шаг %/кг, разгрузка), предпросмотр кривой на базе 100 кг, подпись «Изменения — для новых назначений», удаление (назначенные остаются — снимок).

**Назначение** — «Назначить программу» во вкладке «План» карточки клиента; диалог в 2 шага: (1) программа и понедельник старта (по умолчанию ближайший, можно текущий); (2) таблица «шаблон → упражнение → база» (предзаполнение: задание тренера → последний рабочий вес клиента → вес шаблона; кардио и на время не показываются) с весом финальной недели. Есть активная — предупреждение «Текущая программа «…» завершится».

**Ход программы** — блок «Программа» во вкладке «План»: «Неделя 3 из 8», следующая разгрузка, «упражнение → вес этой недели → финальной», «Изменить базу», «Завершить досрочно». На `/coach` у клиента — метка «Нед. 3/8».

**Клиент** — в календаре и «Плане на сегодня» к пометке «от тренера · <ник>» добавляется «Неделя 3/8» / «Разгрузка»; в редакторе тренировки пометка задания «от тренера: 4 × 8 · 105 кг (неделя 3/8)».

**Уведомления** (`NotificationType.COACH`): клиенту при назначении — «Новая программа от тренера: <название>, 8 недель с 20 окт.» (push); тренеру за 7 дней до конца — «Программа <клиента> заканчивается через неделю» (в `runNotificationTick`, раз, `remindedAt`).

## Потоки

**Назначение** (`assignProgramAction`, `requireClientOf`, флаг): в транзакции — закрыть активное назначение клиента (как «Завершить досрочно»), создать `ProgramAssignment` + `ProgramBase`, на каждый день — `PlanSeries` (`coachId`, `programAssignmentId`, `startDate` — первый такой день недели не раньше max(старт, сегодня), `endDate` — последний день программы), уведомление. Цель Метрики `coach_program_assign`.

**Запуск тренировки**: `getTemplateTargets(clientId, templateId, date)` — после чтения заданий накладывает программу (флаг включён, активное назначение, шаблон есть среди серий назначения или дней программы-снимка, неделя в пределах): вес — из `programWeek`, подходы — `sets + setsDelta` (подходы — задание → шаблон). Дата: `plan:` — дата вхождения, остальное — «сегодня» в поясе клиента. Возвращает и метку недели для пометки.

**Завершение тренировки**: `applyProgression` пропускает задания по шаблонам активной программы; блок «План тренера» в сводке — «Программа: неделя 3/8».

**Окончание** (досрочно, новая программа, разрыв, конец срока): `endedAt`; будущие вхождения серий назначения убираются (`endDate` = вчера; при разрыве серии удаляет `dropAssignments`); в `CoachTarget.weight` записывается вес последней обычной прошедшей недели по каждой базе с весом > 0 (upsert задания: шаблон + упражнение). Конец срока без действий — запись веса ленивая: при первом чтении заданий после окончания (`getTemplateTargets`) — в той же функции, условным `updateMany` по `endedAt = null` (ставит `endedAt` = день после конца).

**Без флага**: страница, кнопки и метки скрыты, наложение не действует, серии — обычные назначения; уведомление «заканчивается» не отправляется.

## 152-ФЗ, аккаунт

- Удаление клиента — каскад; тренера — `coachId`/`programId` → null (назначение закрывается при чтении: тренера нет).
- `dropAssignments` закрывает активное назначение пары (без записи веса в задания — их тоже удаляют).
- «Мои данные»: клиенту — `programs` (название, старт, недели, правило, базы с названиями упражнений, завершено), тренеру — `coachPrograms` (библиотека). Проверить `e2e/account-data.spec.ts`.
- Новых персональных данных о здоровье нет.

## Тесты

- Unit `lib/coach/program.test.ts`: номер недели (до старта, границы недель, пояс), разгрузка, k с разгрузками и `fromWeek`, % и кг, округление 2,5 / 0,5, «не ниже базы», база 0, проверочный пример, схемы.
- Unit: наложение на задания (чистая часть — функция поверх `Target`), запись веса последней обычной недели.
- e2e `e2e/coach-programs.spec.ts` (флаг глобальный → `mode: "serial"`, только desktop, два контекста — `--workers=8`): тренер создаёт программу с предпросмотром → назначает клиенту с базой → у клиента в календаре «Неделя 1/N», при запуске вес базы; история в БД (`e2e/db.ts`) сдвигает старт на 3 недели назад → вес недели 4 = разгрузка, подходов меньше; завершение досрочно → вес в задании; без флага — веса по заданию.
- Существующие: `coach-plan`, `coach-targets`, `coach-signals`, `account-data` — без регрессий.

## Не в этом цикле

Назначение нескольким; ручная правка отдельных недель; смена повторов по неделям; % от 1RM; программы для самостоятельных пользователей и готовые программы (PPL, 5×5) с правилом.
