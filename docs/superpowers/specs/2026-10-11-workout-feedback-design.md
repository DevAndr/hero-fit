# Оценка тренировки: тяжесть и заметка

Вторая из трёх фич для тренеров (1 — сигналы риска клиентов; 3 — назначение шаблона нескольким клиентам). Работает
для всех пользователей, тренер получает её как бонус.

## Цель

После тренировки человек отмечает, насколько было тяжело (RPE за тренировку, 1–10), и при желании пишет заметку.
Себе — история «как шло», тренеру — то, чего не видно в цифрах: «10 — болела спина». Сейчас тренер видит только
подходы и RIR, общего ощущения нет; комментарии идут только от тренера.

## Решения

- **Где:** карточка «Как прошла тренировка?» в сводке своей завершённой тренировки (`/workouts/<id>`), не в
  диалоге завершения: финиш не замедляется, ответ необязателен и правится позже.
- **Что:** тяжесть 1–10 (обязательна при сохранении) и заметка — свободный текст до 500 символов (может быть пустой).
  Быстрые метки — не сейчас.
- **Подписи шкалы** (`rpeLabel`): 1–2 «Очень легко», 3–4 «Легко», 5–6 «Нормально», 7–8 «Тяжело», 9–10 «На пределе».
- **Уведомление тренеру** — только при заметке или тяжести ≥ 9 и только один раз на тренировку
  (`feedbackNotifiedAt`); правка не уведомляет повторно, тренер видит актуальное.
- **Приватность:** лента друзей, лига и картинка для сторис оценку не получают (лента собирается из `XpEvent.meta`,
  туда оценка не пишется). `hideWeights` на оценку не влияет — друзьям она и так не видна.

## Данные

`Workout`: `rpe Int?` (1–10), `notes String?` — уже есть и не используется, теперь заметка; `feedbackNotifiedAt
DateTime?`. Одна миграция, новых таблиц нет.

## Модули

- `lib/workouts/feedback.ts` — чистые:
  - `feedbackSchema` (Zod): `rpe` — целое 1–10; `note` — `trim`, ≤ 500, пустая строка → `null`;
  - `rpeLabel(rpe: number): string`;
  - `shouldNotifyCoach({ rpe, note, notifiedAt }): boolean` — `notifiedAt = null` и (`note` или `rpe ≥ 9`);
  - `feedbackNotice(name, rpe, note): string` — «Маша: тяжесть 9/10 · болела спина» (заметка до 80 символов с «…»;
    без заметки — «Маша: тяжесть 9/10 — На пределе»).
- `lib/workouts/feedback-actions.ts` — `saveWorkoutFeedbackAction(workoutId, { rpe, note })` ("use server"):
  `requireUser`; только своя тренировка в статусе `COMPLETED` (иначе `{ ok: false, error }`); запись `rpe`/`notes`;
  в той же транзакции — если есть активный тренер (`CoachLink`, `endedAt = null`) и `shouldNotifyCoach` —
  `notify(тренер, { type: COACH, title: feedbackNotice(...), body: «Оценка тренировки», url:
  /coach/clients/<клиент>/workouts/<id> }, { push: true })` и `feedbackNotifiedAt = now`. Ответ —
  `{ ok: true, rpe, note }`.
- `components/workouts/workout-feedback.tsx` — клиентская карточка: радиогруппа 1–10 (`aria-label="Тяжесть"`,
  кнопки с подписью числа), подпись выбранного уровня, `Textarea` «Заметка» (`maxLength` 500, счётчик), «Сохранить»
  (неактивна без тяжести). После сохранения — компактный вид «Тяжесть 7 — Тяжело» + заметка + «Изменить».
- `components/workouts/workout-summary-view.tsx` — слот `feedback?: ReactNode` (над упражнениями); страница своей
  тренировки передаёт `WorkoutFeedback`, страница тренировки клиента у тренера — `CoachFeedbackNote` (блок «Оценка
  клиента»: тяжесть, подпись, заметка; ничего, если оценки нет).
- История: `StatsView` (таблица «История тренировок») — колонка «RPE»; вкладка «Тренировки» клиента у тренера —
  значок «RPE 7» в строке.

## Ошибки

Чужая/незавершённая тренировка, невалидные данные, нет сети — тост с ошибкой, форма сохраняет введённое.

## Тесты

- Unit (`lib/workouts/feedback.test.ts`): схема — 0, 11, 7.5, 501 символ — отказ; пустая заметка → `null`; `rpeLabel`
  на 1, 2, 3, 6, 7, 8, 9, 10; `shouldNotifyCoach` — 8 без заметки нет, 9 да, 5 с заметкой да, уже уведомлён нет;
  `feedbackNotice` с длинной заметкой и без неё.
- e2e (`e2e/workout-feedback.spec.ts`): человек без тренера ставит 7 + заметку → компактный вид → после
  перезагрузки сохранено → «RPE 7» в истории `/stats`; «Изменить» → 5 → сохранено. Клиент тренера ставит 9 → тренеру
  одно уведомление «…: тяжесть 9/10 — На пределе», правка на 10 с заметкой — всё ещё одно; тренер видит «Оценка
  клиента» в сводке и «RPE 10» во вкладке «Тренировки». Клиент тренера ставит 6 без заметки → уведомления нет.

## Вне фичи

Быстрые метки заметки, график недельной нагрузки (тяжесть × длительность), сигнал риска «стабильно на пределе»,
оценка в диалоге завершения и офлайн.
