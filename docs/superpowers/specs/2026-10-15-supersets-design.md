# Суперсеты и круговые

Релиз `release/2026-11-formats`, подпроект 1 из 2 (второй — кардио и упражнения на время), под фича-флагом
`workout_formats` — экспериментально.

## Цель

Соседние упражнения можно связать: подходы делаются по кругу A1 → A2 → (A3…) → отдых. Таймер отдыха не мешает
переходить между упражнениями круга. Сборка — в пару нажатий, в тренировке и в шаблоне.

Успех: суперсет собирается за 1–2 нажатия; внутри круга таймер не запускается, после круга — обычный отдых;
группы переживают сохранение шаблона, старт из шаблона, повтор тренировки и офлайн.

Вне рамок: подходы остаются вес × повторы — рекорды, XP, объём, статистика, цели, босс, рейды, клубы не меняются.
Кардио и упражнения на время — подпроект 2. Отдельный «отдых между упражнениями круга» (всегда 0), ачивки за
суперсеты.

## Термины

Группа — подряд идущие упражнения с одним номером `supersetGroup`. 2 упражнения — «Суперсет», 3–6 — «Круг».
Метки — буква группы и номер в ней: A1, A2, B1, B2 (буквы по порядку групп в тренировке).

## Решения

### Данные

Миграция `supersets`:

```prisma
model WorkoutExercise  { … supersetGroup Int? }  // номер группы; null — вне группы
model TemplateExercise { … supersetGroup Int? }
```

Флаг — `workout_formats` в `lib/flags/registry.ts` (`description: "Форматы тренировки: суперсеты и круговые (дальше —
кардио)"`, `expires: "2027-04-30"`).

### Правила — чистые функции `lib/workouts/supersets.ts`

Константа `MAX_GROUP = 6`.

- `normalizeGroups<T extends { group: number | null }>(items: T[]): T[]` — после любого изменения списка:
  группа из одного упражнения → `null`; одинаковый номер, разорванный другим упражнением, — разные группы;
  группа длиннее 6 — режется на части по 6 с начала (хвост из одного — `null`); номера перенумеровываются 1, 2, 3…
  по порядку появления. Возвращает новые объекты только там, где номер изменился.
- `canLink(items, index): boolean` — связать `index` и `index + 1`: оба существуют и итоговая группа ≤ 6.
- `link(items, index)` / `unlink(items, index)` — связать упражнение `index` со следующим (объединяя их группы) /
  отсоединить `index + 1` от `index` (группа делится по этой границе); результат — через `normalizeGroups`.
- `groupLabels(items): (string | null)[]` — метки A1, A2… (`null` вне группы).
- `afterSet(items: { group: number | null; pending: number }[], index: number):
  { kind: "rest"; next: number | null } | { kind: "switch"; next: number }` — что после отметки подхода в упражнении
  `index` (`pending` — невыполненные подходы после отметки):
  - вне группы → `rest`, `next` — само упражнение, если в нём остались подходы, иначе первое следующее с
    невыполненными (как нынешний `nextLabel`);
  - в группе: следующее по кругу после `index` (до конца группы) упражнение группы с `pending > 0` → `switch` на
    него; если `index` — последнее в группе с невыполненными в этом круге (дальше по группе таких нет) → `rest`,
    `next` — первое упражнение группы с `pending > 0`, а если в группе всё выполнено — первое после группы с
    невыполненными;
  - разное число подходов: упражнения с `pending = 0` пропускаются.

### Клиент — редактор тренировки

- `ExerciseState.group: number | null`; `initState` и `toDraft` переносят; черновик `exerciseDraftSchema.group:
  z.number().int().min(1).nullable().default(null).catch(null)` — старые черновики на устройстве читаются.
- Редьюсер: действия `linkNext { key }` и `unlink { key }` (отсоединить следующее); после `addExercises`,
  `removeExercise`, `moveExercise`, `reorderExercise`, `replaceExercise`, `skipPending` — `normalizeGroups`.
  Замена от помощника на месте сохраняет `group`; новое упражнение после текущего вставляется с `group: null` (при
  вставке внутрь группы она по `normalizeGroups` делится).
- Отметка подхода (`onComplete`): `afterSet`; `switch` — таймер не запускается (идущий отдых — сбрасывается),
  тост «Дальше: <упражнение>» и прокрутка к его блоку; `rest` — `rest.start(restSec последнего упражнения группы
  (или самого упражнения), "<название next>")`.
- Вид (только при флаге): между соседними блоками — кнопка-скрепка `aria-label="Связать в суперсет"` (если
  `canLink`), у связанных — `aria-label="Разъединить"`. Связанные блоки — в общей рамке (`data-testid="superset"`)
  с заголовком «Суперсет» / «Круг · N упражнения» и меткой A1/A2 у названия. Свёртывание выполненного — группой:
  рамка сворачивается, когда все упражнения группы свёрнуты.
- Без флага: кнопок, рамок и меток нет, отдых — как сейчас; `group` хранится в состоянии и уходит в черновик как
  есть (данные не теряются).

### Сервер

- `saveWorkoutDraftAction` пишет `supersetGroup` (после `normalizeGroups` — клиенту не доверяем). Без флага — тоже
  пишет присланное (клиент без флага присылает то, что загрузил).
- `ActiveWorkout.exercises[].group`.
- Старт: из шаблона (`fromTemplate`), повтор (`repeat`) — группа переносится, затем `normalizeGroups` (архивное
  упражнение выпало из списка — группа поправляется). План календаря — без групп.
- Шаблоны: `templateItemsFromWorkout` переносит `supersetGroup`; схема шаблона `lib/templates/schema.ts` —
  `group` как в черновике; `saveTemplate` и копирование шаблона пишут `supersetGroup` через `normalizeGroups`.
- Редактор шаблона (`components/templates/template-editor.tsx`) — те же скрепки, рамка и метки при флаге.
- История (`/workouts/[id]`) — у упражнений группы метка A1/A2 и подпись «Суперсет»/«Круг» (при флаге).
- «Мои данные»: `supersetGroup` у упражнений тренировок и шаблонов в JSON.

### «Что нового»

Пункт в следующей записи релиза: «Суперсеты и круговые: свяжите упражнения скрепкой — таймер отдыха включится только
после круга», `flag: "workout_formats"`.

## Тестирование

Unit (`lib/workouts/supersets.test.ts`): `normalizeGroups` — одиночка → null, разрыв → две группы, 7 подряд → 6 +
null, перенумерация; `link`/`unlink` — склейка двух групп, разделение посередине; `canLink` — предел 6, последний
элемент; `groupLabels` — A1 A2 B1 B2; `afterSet` — вне группы, A1 → switch A2, A2 (последнее) → rest на A1, разное
число подходов (у A1 кончились → после A2 rest на A2), группа выполнена → rest на следующее после группы.
Редьюсер (`components/training/workout-state.test.ts`, если есть, иначе рядом): перестановка из группы наружу
разрывает её; удаление упражнения из пары → одиночка без группы.

e2e (`e2e/supersets.spec.ts`, флаг на пользователя `addFlagUser`, desktop и mobile):
- две позиции → «Связать в суперсет» → рамка «Суперсет», метки A1/A2 → подход в A1: таймера нет, «Дальше: …» →
  подход в A2: таймер отдыха → перезагрузка — группа на месте;
- завершить → «Сохранить как шаблон» → старт из шаблона → группа на месте;
- без флага — скрепок нет.

## Review Focus

- Перестановка/удаление/замена ломают группу на «дыры» — всё через `normalizeGroups`.
- Старый черновик на устройстве без `group` и сервер старой версии — без падений.
- Без флага группы не теряются при автосохранении.
