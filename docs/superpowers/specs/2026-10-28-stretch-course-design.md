# Курс «Сесть на шпагат»

Дата: 2026-10-28. Под фича-флагом `stretch_course` (по умолчанию выключен), действует только вместе с `stretching`. Продолжение спеки `2026-10-28-stretching-design.md`.

## Цель

Дать пошаговый план к шпагату вместо набора упражнений: приложение само говорит, что делать на этом занятии, подставляет время удержания и постепенно повышает нагрузку. Программы «Шпагат: продольный/поперечный» остаются как есть — курс их не заменяет.

Вне этапа: свои курсы и курсы от тренера, время удержания в шаблонах, другие навыки (мостик, складки), ачивки и титулы за курс, фото прогресса.

## Решения

- Курс движется **по выполненным занятиям**, а не по календарю: пропуск ничего не сжигает, после перерыва человек продолжает с того же занятия. Дни недели — только для напоминаний.
- Одна длина: **30 занятий = 5 этапов по 6** (≈ 10 недель при 3 занятиях в неделю).
- После 30-го — финальный замер, итог и выбор: «Закрепить» (поддержка) / «Пройти заново» / «Закончить». Результат не обещается: цель-навык засчитывается сама, когда замер дойдёт до 0, — раньше, позже или никогда.
- Награды за курс нет: занятие — обычная сессия растяжки с её XP (`STRETCH_SESSION`), без серии и игровых зачётов.
- План — в коде (`lib/stretching/course.ts`), в базе — только прогресс.

## План

Три курса — по трём навыкам: `SPLIT_LEFT`, `SPLIT_RIGHT` (продольный, нога впереди) и `SPLIT_SIDE` (поперечный). У продольных одинаковый план (односторонние упражнения делаются на обе стороны), различается только засчитываемая цель.

Отдых между подходами — 15 с. Все упражнения — встроенные из `STRETCH_SEED`.

Продольный:

| Этап | Занятия | Удержание | Подходы | Упражнения |
|---|---|---|---|---|
| 1. База | 1–6 | 30 с | 2 | выпад на сгибатели бедра, голубь, растяжка задней поверхности бедра лёжа, растяжка квадрицепса лёжа на боку, складка сидя |
| 2. Подводящие | 7–12 | 45 с | 2 | этап 1 + ящерица, полушпагат |
| 3. Глубже | 13–18 | 45 с | 3 | этап 2, растяжка квадрицепса стоя вместо лёжа на боку |
| 4. Шпагат с опорой | 19–24 | 60 с | 3 | этап 3 + продольный шпагат с опорой |
| 5. Финал | 25–30 | 60 с, шпагат с опорой — 90 с | 3 | как этап 4 |

Поперечный:

| Этап | Занятия | Удержание | Подходы | Упражнения |
|---|---|---|---|---|
| 1. База | 1–6 | 30 с | 2 | бабочка, лягушка, широкая складка сидя, растяжка задней поверхности бедра лёжа |
| 2. Подводящие | 7–12 | 45 с | 2 | этап 1 + боковой выпад, ящерица |
| 3. Глубже | 13–18 | 45 с | 3 | как этап 2 |
| 4. Шпагат с опорой | 19–24 | 60 с | 3 | этап 3 + поперечный шпагат с опорой |
| 5. Финал | 25–30 | 60 с, шпагат с опорой — 90 с | 3 | как этап 4 |

- **Замер** — на занятиях 1, 7, 13, 19, 25 и 30 (`isMeasureSession`): первое занятие этапа и последнее.
- **Поддержка** — занятия после 30-го идут по плану этапа 5 бесконечно; замера в поддержке нет (его можно внести в цели как обычно).
- Время в подходах — подставленное значение: человек может поправить его вручную, как любой подход.

## Данные

```prisma
enum StretchCourseStatus {
  ACTIVE       // идёт, nextSession 1…30
  MAINTENANCE  // поддержка после финала, nextSession > 30
  COMPLETED    // «Закончить» после финала
  ABANDONED    // «Бросить курс»
}

model StretchCourse {
  id          String              @id @default(cuid())
  userId      String
  user        User                @relation(fields: [userId], references: [id], onDelete: Cascade)
  skill       String              // ключ навыка, как Goal.stretchSkill: SPLIT_LEFT | SPLIT_RIGHT | SPLIT_SIDE (проверка в коде)
  goalId      String?
  goal        Goal?               @relation(fields: [goalId], references: [id], onDelete: SetNull)
  remindDays  Int[]               // 0 = пн … 6 = вс; пусто — без напоминаний
  nextSession Int                 @default(1)
  status      StretchCourseStatus @default(ACTIVE)
  startedAt   DateTime            @default(now())
  finishedAt  DateTime?           // 30-е занятие пройдено
  remindedDay String?             // местный день последнего напоминания (YYYY-MM-DD)
  workouts    Workout[]
  @@index([userId])
}

// Workout
courseId        String?
course          StretchCourse? @relation(fields: [courseId], references: [id], onDelete: SetNull)
courseSessionNo Int?
```

- `skill` — строка, как `Goal.stretchSkill`; допустимые значения — `COURSE_SKILLS` (три ключа шпагата) в `lib/stretching/course.ts`.
- Частичный уникальный индекс `StretchCourse_active` на `userId` при `status IN ('ACTIVE', 'MAINTENANCE')` — один идущий курс. Prisma его не видит: добавить в список в CLAUDE.md («Сквозные правила») и проверять SQL следующих миграций.
- Замеры — `StretchMeasurement` цели-навыка (`goalId`), отдельного хранения нет. Стартовый и финальный замеры для итога — первый и последний замер цели в интервале курса.

## Поведение

### Старт (`startCourseAction`)

Диалог из трёх шагов: вид (продольный — левая/правая впереди, поперечный) → дни напоминаний (по умолчанию пн/ср/пт, можно снять все) → стартовый замер, см (обязателен). Предупреждение «Тянитесь до натяжения, не до боли, и только после разминки».

- Есть активная цель `STRETCH_SKILL` с этим навыком — курс привязывается к ней, замер пишется в неё (тем же кодом, что «Замер» на карточке цели: один замер в день, повтор заменяет).
- Нет — создаётся цель-навык (как из диалога цели, с тем же лимитом активных целей; упёрлись в лимит — отказ с понятным текстом).
- Уже идёт курс (ACTIVE или MAINTENANCE) — отказ.

### Занятие (`startCourseSessionAction`)

- Есть незавершённая тренировка — ведём в неё (не создаём вторую), как «Начать растяжку».
- Иначе — `createWorkout` из `sessionPlan(skill, n)`: название «Шпагат · занятие N» (в поддержке — «Шпагат · поддержка»), подходы с `durationSec` = целевое время, отдых 15 с; `courseId`, `courseSessionNo = n`; тренировка сразу запускается (`IN_PROGRESS`) и открывается `/training`.
- В шапке тренировки — «Курс: этап S · занятие N из 30» (в поддержке — «Курс: поддержка»). Перед первым упражнением — подсказка «Разомнитесь 5 минут: ходьба, махи ногами. Не до боли».
- На занятии с замером — плашка «Замер: см до пола» с полем и «Пропустить»; сохранение — тот же экшен замера цели. Плашка не блокирует завершение.

### Засчитывание

В `finishWorkout` (в той же транзакции): у тренировки есть `courseId`, выполнен хотя бы один подход, курс ACTIVE/MAINTENANCE и `courseSessionNo === nextSession` → `nextSession + 1`. Условие на `courseSessionNo` делает повторное завершение и старую тренировку безопасными. После 30-го — `finishedAt = now`, статус остаётся ACTIVE до выбора на экране итога.

Отменённая тренировка курс не двигает. Удалённая тренировка курса счётчик не откатывает.

В сводке тренировки курса — «Занятие N из 30 пройдено · следующее — этап S, X с».

### Финал

После 30-го занятия карточка курса показывает итог: «Было A см → стало B см · 30 занятий · W недель» и кнопки:
- «Закрепить» — `MAINTENANCE`, напоминания продолжаются по тем же дням (их можно поменять);
- «Пройти заново» — текущий `COMPLETED`, сразу диалог старта нового курса с этим же видом;
- «Закончить» — `COMPLETED`.

Финального замера не было (пропустили) — «стало» — последний замер, иначе строка без сравнения.

### Бросить и дни

«⋯» на карточке: «Дни напоминаний» (тот же выбор, что на старте) и «Бросить курс» (подтверждение) → `ABANDONED`. Новый курс можно начать сразу. Сам курс не бросается никогда.

### Карточка на `/stretching`

Над целями. Без курса — «Курс «Сесть на шпагат» · 10 недель, 30 занятий» и «Начать курс». С курсом — вид, «Этап S из 5 · Занятие N из 30», полоса, последний замер, «Начать занятие» (при незавершённой тренировке — «Продолжить тренировку»). Завершённые и брошенные курсы — не показываем (история — в выгрузке).

### Напоминания

Новый шаг тика `course` (`TICK_STEPS`), новый `NotificationType.COURSE_REMINDER`, тумблер «Курс растяжки» в настройках уведомлений — `User.notifyCourse Boolean @default(true)`, рядом с `notifyGoal`:
- `notifyCourse` включён, курс ACTIVE или MAINTENANCE, сегодня (в `User.timeZone`) — день из `remindDays`, местное время ≥ 17:00, `remindedDay` ≠ сегодня, сегодня нет завершённой тренировки курса;
- текст: «Сегодня занятие курса: этап S, занятие N из 30» (поддержка — «Сегодня занятие поддержки шпагата»), ссылка `/stretching`;
- каналы — как у остальных напоминаний (push, Telegram, лента).
- без флага `stretch_course` или `stretching` у пользователя — не шлём.

## Флаг `stretch_course`

Ключ в `lib/flags/registry.ts`. Без него (или без `stretching`): нет карточки курса, экшены курса отказывают, напоминаний нет. Уже созданные тренировки курса остаются обычными сессиями растяжки в истории. Пункт «Что нового» — с `flag: "stretch_course"`. e2e включают флаг пользователю.

## Данные пользователя (152-ФЗ, «Мои данные»)

- Выгрузка: `stretchCourses` — вид, статус, дни, `nextSession`, `startedAt`, `finishedAt`; без id.
- Удаление аккаунта — каскадом от `User`; проверка в `e2e/account-data.spec.ts`.

## Тесты

Unit (`lib/stretching/course.test.ts`):
- `sessionPlan`: этапы, состав, подходы и секунды на границах 1/6/7/12/13/18/19/24/25/30; шпагат с опорой — 90 с только на этапе 5; поддержка (31, 100) = этап 5; все упражнения есть в `STRETCH_SEED`.
- `stageOf`, `isMeasureSession`.
- Сдвиг счётчика: совпадает `courseSessionNo` → +1; не совпадает или нет выполненных подходов → без изменений; после 30 — `finishedAt`.
- Условие напоминания (чистая функция): день недели, 17:00, `remindedDay`, занятие сегодня.

e2e (`e2e/stretch-course.spec.ts`, desktop + mobile):
- старт курса: цель-навык создана, замер записан; первое занятие — подходы по 30 с, плашка замера; завершение → «Занятие 1 из 30 пройдено», карточка — занятие 2;
- отменённая тренировка курса не двигает;
- существующая цель-навык — курс к ней привязался, вторая цель не создана;
- финал: курс на занятии 30 (подготовка в БД) → завершение → итог → «Закрепить» → карточка «поддержка»;
- напоминание: `runTick(request, now, "course")` в день из `remindDays` после 17:00 — одно уведомление, повторный тик — ни одного;
- без флага — нет карточки, экшен отказывает.
- `account-data`: курс в выгрузке, удаляется вместе с аккаунтом.
