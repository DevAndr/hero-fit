# Telegram: бот и Mini App

Подробности фич (перенесено из CLAUDE.md). Меняешь поведение области — обнови этот файл.

- Telegram-бот (спека `docs/superpowers/specs/2026-10-10-telegram-bot-design.md`, подпроект 1 из 3: привязка и уведомления; дальше — Mini App со входом из Telegram, оформление): без `TELEGRAM_BOT_TOKEN`/`TELEGRAM_BOT_USERNAME` выключен целиком (карточки в `/settings` нет, webhook — 404), `TELEGRAM_WEBHOOK_SECRET` — 32+ символа. Привязка — карточка «Telegram» в `/settings` → `createTelegramLinkAction` (одноразовый `TelegramLinkToken`, 15 мин) → `t.me/<бот>?start=<токен>` → `handleUpdate` (`lib/telegram/updates.ts`; `linkChat` — условная отметка `usedAt`, чат прежнего аккаунта отвязывается: один Telegram — один аккаунт), `/stop` и 403 при отправке отвязывают. Входящие — `POST /api/telegram/webhook` (секрет в `X-Telegram-Bot-Api-Secret-Token`, после проверки всегда 200), регистрация — `npm run telegram:webhook` или curl из `deploy/README.md`; локально без публичного адреса — `TELEGRAM_POLLING=on` (`getUpdates` в `lib/telegram/polling.ts`, снимает webhook). Исходящие — второй канал в `processDuePushes`: `sendTelegramToUser` (`lib/telegram/send.ts`) читает `telegramChatId`/`notifyTelegram` в момент отправки, `REST` не шлёт; переключатели по типам общие с push (применяются при постановке в очередь). Сообщение — чистая `telegramMessage` (`lib/telegram/format.ts`: HTML с экранированием, кнопка «Открыть» только при публичном https `APP_URL`), клиент Bot API — `callBot` на `fetch` (не бросает, таймаут 10 с). `telegramChatId` — BigInt, в клиент не передаётся (`getTelegramStatus`). В e2e — фейковый Bot API `e2e/telegram-server.ts` (второй `webServer`, порт 3124: `GET /calls?chat_id=`, `POST /block?chat_id=` → 403), хелперы `telegramToken`/`telegramChat`/`linkTelegram`/`queuePush`/`setNotifyTelegram` (`e2e/db.ts`), chat id — уникальные на тест (сервер общий)
- Telegram Mini App (спека `docs/superpowers/specs/2026-10-10-telegram-mini-app-design.md`, подпроект 2 из 3): тот же сайт, точка входа `/tg` (публичная, BotFather → Main Mini App) — `MiniAppEntry` (`components/telegram/mini-app-entry.tsx`) шлёт `Telegram.WebApp.initData` в `POST /api/telegram/auth` (`auto` | `register` с `consent: true` | `link` по логину/паролю); подпись — чистая `verifyInitData` (`lib/telegram/init-data.ts`: HMAC `WebAppData`, `auth_date` ≤ 24 ч и ≤ +5 мин), переход — `startTarget` (`join_<код>` → `/coach/join/<код>`, иначе `/dashboard`). Вход — по `User.telegramId` (отдельно от `telegramChatId` уведомлений: `/stop`, «Отключить» и 403 бота снимают только уведомления; ссылка бота входа не даёт — её можно подсунуть, поэтому подключивший бота при первом открытии Mini App привязывается паролем); новый — `registerFromTelegram` (`lib/telegram/mini-app.ts`): `login = tg<id>` (занят — `tg<id>_<4 цифры>`; на сайте `tg<цифры>` зарезервирован в `registerSchema`), без email и пароля (`User.email`/`passwordHash` — nullable; вход с паролем и восстановление для них молча не срабатывают), повтор регистрации — вход в созданный; `link` переносит Telegram с прежнего аккаунта, но не с аккаунта без пароля (там он единственный вход — 409 `telegram_in_use`). `initData` действителен 1 ч; на `/tg` Метрика не грузится (`metrikaOff`: в адресе `#tgWebAppData`). Выход и отозванная сессия удаляют cookies Mini App с атрибутами фрейма (`clearAuthCookies(…, { embedded })`, `sessionEmbedded`). Сессия Mini App — `Session.embedded`: cookies `SameSite=None; Secure; Partitioned` (для фрейма web.telegram.org; чистая `authCookieOptions` в `lib/auth/cookie-options.ts`, ротация в `proxy.ts` сохраняет атрибуты); встраивать сайт может только Telegram — `frame-ancestors 'self' https://web.telegram.org` (вместо `X-Frame-Options: DENY`). Без пароля в `/settings` — блок «Вход на сайте» (`setSiteLoginAction`). Тренеру — «Ссылка для Telegram» (`telegramJoinUrl`, `lib/telegram/links.ts`) в «Пригласить клиента» и «Заниматься в Telegram» на странице тренера. Цели Метрики `signup` и `telegram_open`. В e2e — `mockTelegram` (`e2e/telegram-webapp.ts`: подменяет `telegram-web-app.js`, `initData` подписан e2e-токеном), `createTelegramUser` (`e2e/db.ts`). Оформление под Telegram (спека `docs/superpowers/specs/2026-10-11-telegram-mini-app-polish-design.md`, подпроект 3 из 3): признак — `CurrentUser.embedded` (из `Session.embedded`), layout `(app)` оборачивает кабинет в `TelegramMiniApp` (`components/telegram/telegram-mini-app.tsx`; SDK грузится только для встроенных сессий; без `initData` — ничего не делает): `ready`/`expand`/`disableVerticalSwipes`, тема — только по `colorScheme` (`themeForScheme`, `themeChanged`), цвета фирменные, шапка/фон/нижняя панель Telegram — цветом фона страницы (oklch → hex через canvas), системная «Назад» — скрыта на корневых (`NAV_ITEMS` + `/coach`, `isRootPath`), иначе `router.back()` при истории в приложении, без неё — `backTarget` (`lib/telegram/back.ts`), безопасные зоны — `--tg-safe-top/bottom` (8.0+). Вызовы SDK — только через `tg()`/`tgCall`/`tgSupports` (`lib/telegram/webapp.ts`: старые клиенты, ошибки глотаются), вибрация — `haptic` (подход — light, конец отдыха — warning, уровень/рекорд/ачивка — success; в серверных страницах — `<Haptic>`), `useTelegram()` → `inTelegram`, `useClosingConfirmation` — в редакторе тренировки. В Telegram скрыты выбор темы («Тема — как в Telegram»), `PushDeviceCard` и кнопка push таймера отдыха. В e2e `mockTelegram` пишет вызовы SDK (`tgCalls`), шлёт события (`tgEmit`) и жмёт «Назад» (`tgBack`), опции `colorScheme`/`version`
