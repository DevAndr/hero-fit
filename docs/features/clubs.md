# Клубы залов

Подробности фич (перенесено из CLAUDE.md). Меняешь поведение области — обнови этот файл.

- Клубы залов (спека `docs/superpowers/specs/2026-10-12-clubs-design.md`, цикл 1 из 2; цикл 2 — общие задания клуба; под флагом `clubs`): `Club` (город/адрес текстом, ключи `nameKey`/`cityKey`/`addressKey` — `clubKey`; `contact` видит только модератор; `code` — приглашение алфавитом кода друга; `status` `PENDING` → `APPROVED` | `REJECTED` (`rejectReason`) | `HIDDEN`), `ClubMember` (`userId` — ключ: один клуб на человека, `joinedAt`), `ClubBan` (исключение = бан до разблокировки). Заявку подаёт любой с флагом (`/clubs/new`, галочка «Я представляю этот зал», похожие клубы — `similarClubs`; лимиты `createBlock`: до 5 клубов и 3 заявок), заявитель — админ клуба (не обязан быть участником). Модерация — `/admin/clubs` (`requireAdmin`, без флага; `reviewClubAction` — условный `updateMany` по `PENDING`, уведомление `SOCIAL`; `setClubHiddenAction`; правка — тот же `updateClubAction`), пункт «Клубы N» в меню профиля админа (`pendingClubCount` в layout). Правила — чистые `lib/club/rules.ts`, запросы — `lib/club/queries.ts`, действия — `lib/club/actions.ts` (флаг — `clubsAllowed`, страницы — `requireClubs` → 404). `/clubs` (участника переадресует в его клуб, кроме `?list=1`; поиск — GET-форма, `ILIKE` через `likePattern`), `/clubs/[id]` (видимость по статусу; участнику — вкладки «Рейтинг» Неделя/Месяц и «Лента», остальным — топ-3 недели и «Вступить»), `/clubs/join/[code]` (экран согласия; вступление — `joinClubAction` под `FOR UPDATE` строки клуба), `/clubs/[id]/manage` (правка, ссылка с QR — `uqr` в браузере, исключение, разблокировка, передача по нику, «Сменить ссылку»). Рейтинг — `getClubRating` (очки лиги, `rankLeague`, опыт до вступления считается, нули — «Ещё N без тренировок»). Лента — только события: свой SQL без упражнений/объёма/👊, тренировки после `joinedAt`, авторы с `shareActivity`; чистые `toClubEvents`/`collectEvents` (`lib/club/feed.ts`, до 3 запросов на подгрузку). Пункт «Клуб» — в боковом меню после «Гильдии» и в меню профиля (`useFlag`). В e2e — `createClub`/`clubOf`/`clubStatus`/`setClubStatus`/`clubAdminLogin`/`joinClub`/`seedXpWorkout` (`e2e/db.ts`), модерация — `e2e/clubs-moderation.spec.ts` (serial, только desktop: `makeAdmin`)
- Публичная страница клуба (спека `docs/superpowers/specs/2026-10-12-club-public-page-design.md`, флаг `clubs`): поля `Club.about`/`slug`/`citySlug`/`publishedAt`/`updatedAt`; адрес `/gym/<citySlug>/<slug>` — транслит (`slugify`, варианты `slugCandidates`: название → с улицей → `-2…-20`), ставится при первой публикации и больше не меняется (правка названия/города не двигает). Правила — чистые `lib/club/public.ts` (`canPublish`: одобрен и «О зале» от 50; `visibleClubStats`: цифры клуба от 3 участников; `clubPageAccess`: всем — одобрен + опубликован + флаг на 100 % (`isEnabled("clubs", null)`), админу клуба и приложения — предпросмотр с плашкой и noindex, `HIDDEN`/`REJECTED` — 404 всем), запросы — `lib/club/public-queries.ts` (`resolveClubPage`, `getClubPublicStats` — тренировки участников после вступления за 7/30 дней, `getCityClubs`, `getPopularCities`). Страницы — `app/(marketing)/gym/` (клуб, город `/gym/<city>`, `join` → `/clubs/join/<код>`, гостю через регистрацию, цель `club_page_join`), `/gym/` в `PUBLIC_PREFIXES`; ников и `contact` на публичных страницах нет. SEO — `clubJsonLd` (`ExerciseGym`), `cityJsonLd` (`ItemList`), `shortDescription` (общая с тренером), `sitemap.xml` — клубы и города только при 100 % флага. Редактор — раздел «Публичная страница» (`#public`) в `/clubs/[id]/manage` (`ManagePublicPage`; `saveClubAboutAction`, `publishClubPageAction` — перебор адресов по P2002, цель `club_page_published`, `unpublishClubPageAction`). Модерация — «О зале» и «Страница зала» в карточке `/admin/clubs`, «Снять с публикации» с причиной (`unpublishClubByModeratorAction`, уведомление админу клуба). Лендинг — раздел `#clubs` «Клубы залов» (`ClubInfographic`, «Популярные города»), пункт «Клубы» в шапке и подвале (проп `clubs` из layout marketing), строка `FREE_PLAN` и 2 вопроса FAQ (`faqFor`, и в JSON-LD) — всё только при 100 % флага. В e2e — `publishClub`/`clubSlug` (`e2e/db.ts`), `e2e/club-public-page.spec.ts` — отдельный проект Playwright `clubs-global` (desktop, `dependencies: ["desktop", "mobile"]` — идёт после всех: переключает флаг `clubs` для всех, а соседние спеки клубов держатся на флаге списком; запуск только его — `--project=clubs-global` тянет весь прогон, без зависимостей — `--project=clubs-global --no-deps`)
- Карточка клуба на дашборде (рядом с «Гильдией», две колонки на `md+`; без флага `clubs` — только гильдия): `getClubDashboard` (`lib/club/dashboard.ts`) — участнику место недели (`getClubRating`), задание — чистая `pickCardTask` (`lib/club/tasks.ts`: начавшиеся, невыполненные, раньше кончается) и «Сундук ждёт» (любой открываемый сундук клуба, ссылка — `?tab=tasks`); не участнику — своя заявка «на проверке» или призыв → `/clubs`. Компонент — `components/club/club-card.tsx`, e2e — `e2e/club-card.spec.ts`
- Задания клуба (клубы, цикл 2 — спека `docs/superpowers/specs/2026-10-12-club-tasks-design.md`, флаг `clubs`): `ClubTask` (`type` `WORKOUTS`/`VOLUME`/`REPS` (+ встроенное `exerciseId`)/`HOURS` (в минутах), `mode` `CLUB` «всем клубом» / `EACH` «каждому», `target`, окно `startsAt`…`endsAt` — `taskWindow` в поясе админа, `membersAtStart`, `cancelledAt`, `completedAt` — только `CLUB`), `ClubTaskHit` (вклад тренировки, уникален `(taskId, workoutId)`), `ClubTaskReward` (сундук, `openedAt`). Правила — чистые `lib/club/tasks.ts`: `minTarget` (на неделю срока: `EACH` — 2 тренировки / 5 000 кг / 200 повторов / 2 ч; `CLUB` на участника — 2 / 2 000 / 100 / 2; недели дробно, вверх, кг — до 100, часы — до часа), `taskBlock` (до 3 активных), `workoutAmount` (только выполненные рабочие подходы), `hitCounts` (окно, `joinedAt`, отмена, офлайн-финиш до 24 ч после окна), `eligible` (порог сундука `CLUB`: ≥ 1 % цели или ≥ 1 тренировка), `taskTitle`/`taskFeedTitle`, `chestBlock` (не больше 2 открытых за неделю в поясе игрока — «Откроется с понедельника»), `chestExpired` (4 недели после `endsAt`). Вклад — `applyClubTasks` в транзакции `finishWorkout` после рейда (`lib/club/tasks-apply.ts`: `FOR UPDATE` строки задания, `EACH` — сундук при пересечении цели, `CLUB` — условный `updateMany` по `completedAt`, сундуки вышедшим на порог (и вышедшим из клуба), уведомление `SOCIAL`: им с push, остальным участникам без) → `FinishMeta.clubTasks` → блок «Задания клуба» в сводке и события ленты клуба (`ClubEvent.tasks`/`clubTasks`; `feedTitle` — всегда «скрытый» вариант, выбор по `hideWeights` при чтении). Сундук — `openClubTaskChestAction` (75 XP, `XpReason.CLUB_TASK_REWARD`, не в лиге и рейтинге; блокировка строки пользователя), кнопка прячется после открытия, диалог остаётся смонтированным. Чтение — `getClubTasks` (`lib/club/tasks-queries.ts`; `EACH` — только свой прогресс и «Выполнили: N», `CLUB` — общий прогресс и вкладчики в %, не участнику — только активные с общим прогрессом `CLUB`; `daysLeft`/`started` считает сервер). UI: вкладка «Задания» на `/clubs/[id]` (первая и по умолчанию при активных; `?tab=tasks|rating|feed`), раздел «Задания» в `/clubs/[id]/manage` (`ManageTasks`: диалог «Новое задание» с подсказкой «Минимум: N» — `taskMinimumAction`, «Отменить»). Ачивки `clubtask:N` (1, 5, 10, 25) «Командный игрок», категория `CLUB`, счётчик — число `ClubTaskReward`; титул `ach:clubtask:25` «Душа клуба». Модерация: поиск `?q=` и на вкладке «На проверке» (список — 100 самых старых). В e2e — `createClubTask`/`clubTaskOf`/`clubTaskRewards` (`e2e/db.ts`), сценарии — `e2e/club-tasks.spec.ts` (`--workers=8`); `seedXpWorkout` пишет упражнение с подходом и `records: []` — без них падает сборка итогов недели
