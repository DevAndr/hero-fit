- Тренировка: активная (PLANNED/IN_PROGRESS) — максимум одна на пользователя; редактор держит состояние на клиенте (`components/training/workout-state.ts`, чистый reducer) и автосохраняет черновик целиком (`saveWorkoutDraftAction`). Без сети (`components/training/use-workout-sync.ts` + `offline-store.ts`): каждое изменение сразу в `localStorage` (`hf:workout:<id>`), на сервер — очередью старт → черновик → финиш; старт и финиш несут время с устройства (`clampClientTime`: не в будущем, старт ≤ 12 ч назад, финиш ≥ старта). Повтор — событие `online`, возврат в приложение, раз в 15 с, кнопки «Синхронизировать»/«Отправить сейчас». Черновик с устройства подставляется после монтирования (`replace`), если он не отправлен и новее `updatedAt` сервера. Чистка черновиков — только при наличии сети (страница без сети может быть устаревшей копией из кэша). Service worker (`public/sw.js`, регистрируется и без push): `/training` — network-first с копией в `hf-pages-v1`, `/_next/static` — cache-first, остальные страницы без сети — заглушка; кэш страниц чистится при `/login` и выходе. e2e без сети — `context.setOffline` (`e2e/offline.spec.ts`). На ПК (`lg`) справа каталог упражнений: перетаскивание в список и смена порядка за ручку — `@dnd-kit` (`components/training/workout-dnd.tsx`, цель — блок ближе к курсору), на мобильных — диалог `ExercisePicker`; в e2e добавлять упражнения через `addToWorkout` (`e2e/helpers.ts`). Числовые поля (вес и повторы подходов, поля шаблона и заданий тренера) при фокусе выделяют значение — пропсы `selectOnFocus` (`components/ui/select-on-focus.ts`: Tab — выделение в следующем кадре, если ещё не печатали; тап/клик — на `click`, иначе телефоны ставят курсор после выделения); новое числовое поле ввода данных тренировки — с ними же, сценарий — `e2e/select-on-focus.spec.ts`. Завершение — `lib/workouts/finish.ts` (одна транзакция: чистка невыполненных подходов, итоги, PR, XP, уровень, недельный streak; meta для сводки в `XpEvent`, включая `weekCount`)
- Сворачивание выполненных упражнений в редакторе: упражнение, где отмечены все подходы, сворачивается в строку «✓ название · 3/3 · 60×10, …» без полей ввода, когда подход отмечен в другом упражнении (последнее в работе остаётся открытым — там выбирают запас повторов; после перезагрузки — то же правило).
