# Питание: норма калорий и расход на тренировках

- Норма и расход (спека `docs/superpowers/specs/2026-10-31-nutrition-norm-design.md`, план `docs/superpowers/plans/2026-10-31-nutrition-norm.md`, подпроект 1 из 4: дальше дневник питания, база продуктов, игровой слой) под флагом `nutrition`: страница `/nutrition` (без флага — 404), пункт «Питание» (`NUTRITION_NAV_ITEM`) в боковом меню после «Целей», на телефоне — в меню профиля. Анкета (`NutritionProfileDialog`, `saveNutritionProfileAction`, Zod — `nutritionProfileSchema` в `lib/nutrition/schema.ts`: год рождения 1926…текущий − 14, рост 120…230, вес 30…300): поля `User.heightCm`, `birthYear` (только год — минимум данных), `activityLevel` (`ActivityLevel`), `nutritionGoal` (`NutritionGoal`), пол — общий `User.gender`, вес — обычным взвешиванием (`logBodyWeightAction`: журнал, цель по весу, ачивки). «Очистить данные питания» (`clearNutritionProfileAction`) обнуляет четыре поля, пол и вес остаются. Данные на сервере, по желанию пользователя; входят в «Мои данные» (`PROFILE_FIELDS`), пункт в `/privacy`.
- Норма — чистая `dailyNorm` (`lib/nutrition/norm.ts`): Миффлин–Сан Жеор (`10·вес + 6,25·рост − 5·возраст + 5` / `− 161`), × активность (1,2 / 1,375 / 1,55 / 1,725 / 1,9), цель (похудение × 0,85, набор × 1,10), минимум 1200 (жен.) / 1500 (муж.), до 10 ккал; БЖУ: белок 1,8 г/кг (похудение — 2,0), жиры 0,9 г/кг, углеводы — остаток (не меньше 0). Норма фиксированная: сожжённое на тренировках к ней не прибавляется (уже в коэффициенте активности).
- Расход — чистая `workoutKcal` (`lib/nutrition/burn.ts`): WHOOP (`kcal` только из карточки `data` — `whoopKcalOf`; «ждём», «нет совпадения», переподключение → MET) в приоритете, иначе `MET × вес × часы` до 5 ккал, часы — не больше 3 (`MAX_BURN_HOURS`: забытая тренировка не даёт тысячи ккал); MET — среднее по выполненным рабочим подходам (без разминки): силовые 5, на время 4, кардио 7, растяжка 2,5; вес на дату тренировки — `weightOn` (последняя запись не позже даты, иначе самая ранняя). Запросы — `lib/nutrition/queries.ts`: `getNutritionView` (норма, расход за 7 местных дней, по дням и список с меткой WHOOP) и `getWorkoutBurn` (плитка «≈ N ккал» — `BurnTile` — в сводке тренировки, когда у WHOOP нет ккал по этой тренировке, в слоте `wearable`). В интерфейсе расход всегда с «≈», сноска «Оценка по формулам, не медицинская рекомендация».
- Дневник (спека `docs/superpowers/specs/2026-10-31-nutrition-diary-design.md`, план `docs/superpowers/plans/2026-10-31-nutrition-diary.md`, подпроект 2, тот же флаг): `FoodEntry` (местная дата строкой, `meal` — `Meal`: завтрак/обед/ужин/перекус, название 1…80, ккал 0…5000, Б/Ж/У 0…500 по желанию — `foodEntrySchema`). На `/nutrition` сверху — навигация по дням (`DayNav`, `?date=`, разбор — `parseDiaryDate`: мусор и будущее → сегодня, старше 365 дней → граница), «Итог дня» (`DaySummary`: съедено / норма, `balance` → «Осталось N» / «+N сверх нормы», полоски Б/Ж/У; без нормы — суммы и «Посчитать норму»), 4 блока приёмов (`MealBlock`, суммы — `dayTotals`), ниже карточки нормы и расхода. Диалог записи (`FoodEntryDialog`) с «Недавними» (`getRecentFoods`: до 8 названий без учёта регистра за 30 дней по частоте, значения из последней записи). Действия (`lib/nutrition/food-actions.ts`, только свои записи): добавить в день, изменить, удалить, «Добавить сегодня» (копия в тот же приём), «Повторить вчерашний» (только в пустой приём; строка `User` блокируется в транзакции — двойной клик не задваивает). Записи — раздел `food` в «Мои данные», удаление аккаунта — каскад. e2e — `e2e/nutrition-diary.spec.ts` (`addFoodEntry`, `foodEntries` в `e2e/db.ts`).
- Режим ввода: `User.nutritionMacros` (по умолчанию `false` — только ккал), переключатель «Белки, жиры, углеводы» в «Итоге дня» (`MacrosSwitch`, `setNutritionMacrosAction`, сохраняется сразу). Без него скрыты поля Б/Ж/У в диалоге записи (уходят скрытыми полями — правка ккал не стирает уже введённые БЖУ, «Недавние» их тоже заполняют), полоски Б/Ж/У в итоге дня, строка «Б · Ж · У» у записей и плитки Б/Ж/У в норме. Поле — в «Мои данные». e2e — в `e2e/nutrition-diary.spec.ts` (`setNutritionMacros` в `e2e/db.ts`).
- e2e — `e2e/nutrition.spec.ts` (флаг на пользователя — `addFlagUser`), выгрузка — `e2e/account-data.spec.ts`; анкета напрямую — `setNutritionProfile` (`e2e/db.ts`).
